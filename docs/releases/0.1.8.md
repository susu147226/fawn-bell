# 鹿铃 0.1.8

## 归档素材：整个重写

旧实现是在原地反复修补，这次**从头重写**，并改了最关键的一点：**所有路径先去掉 `\\?\` 扩展前缀**
再使用。列表里选中的路径内部都带这个前缀，而 `CreateDirectoryW` / `MoveFileW` 对扩展路径的行为
和普通路径不一样——失败时既不报错也什么都不做，表现出来就是"点了没反应"。

新实现的行为与 `refile.py` 一致：按前缀建文件夹、移入 PNG、把同目录 XML 复制进去并按 PNG 实际
尺寸改写 `screenWidth` / `screenHeight` 与 `Image` 的 `src`，然后删掉主目录的 XML。

并且每一步都写进 `%LOCALAPPDATA%\Luling\refile.log`；没选中 PNG 或有条目没做成时会弹框说明。

## 批量重命名：三个问题

- **默认规则框里残留一个 `{`** —— 上次去掉 `{n}{ext}` 时字符数写成了 7，实际是 8 个字符，于是留下
  了一个花括号。已改正。
- **前缀后不再自动补下划线以外的分隔**：输入 `date` 得到 `date_0.png`；输入 `date_`、`date-`
  或带空格结尾时不会重复添加分隔符。
- **「更多选项」与规则输入框间距太小**：按钮上移、输入框下移，两者不再贴在一起。

## 安装

仍未能解决。错误已经精确定位到**创建 `%LOCALAPPDATA%\Programs\Luling` 被拒绝访问**——而这个目录
我这边验证过是可读可写的（`Python`、`Xmind` 就装在里面），所以是**安装器进程被针对性拦截**，
不是路径或权限配置的问题。下一步我会改成不经过安装器的方式（由程序自身完成部署）。
