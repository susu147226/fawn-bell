### 暂存盘

- 新增文本对比窗口：暂存盘比较两个文本文件时，点击“查看差异”或在批量菜单选择“对比这两个文件”即可打开。支持并排/统一视图、行内字符差异高亮、仅显示差异、忽略空白和大小写、左右交换、F7/Shift+F7 跳转、缩略条定位和复制选中内容，并显示编码与换行符。
- 暂存盘新增比较模式，可对照两个项目的位置、修改时间、大小与内容是否相同；二进制文件会单独标注。
- 已移动或删除的暂存项会提示失效，可一键移出。
- 批次可切换复制或移动：拖放默认复制，按住 Shift 为移动；复制批次在放下后仍保留。整个暂存盘可一次拖出到目标位置。

### 浏览与搜索

- 新增列表分组：可按名称、日期、类型或大小分组，工具栏常驻“分组”按钮，每个文件夹分别记住设置；下载和最近默认按日期分组。
- 新增双栏文件夹对比，快速标出两侧不同、缺失和较新的项目。
- 重新设计地址栏搜索：搜索框更宽，筛选标签不再截断，提示样式统一。
- 改进高级搜索交互，并保留搜索条件与状态。
- 鼠标中键在后台标签打开文件夹，Ctrl+中键在前台标签打开。

### 界面与体验

- 新增上下文操作提示，帮助发现快捷键和隐藏功能，可在设置中关闭或重置。
- 文字渲染新增“自动 / 清晰 / 平滑”三种模式。
- 修复输入框光标显示问题，以及其他稳定性与细节改进。

提供 Windows 10/11 x64 安装版。不同系统的预览组件和视觉效果可用性可能不同。
