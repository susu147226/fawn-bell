### Update and restart

- One click downloads and verifies the installer, waits for file operations or index migration, and continues automatically without another download or Retry prompt.
- Pulse saves the window, tabs, and split layout before closing. The silent update then reopens your workspace, even when normal launches are configured to open the default location. Your startup preference stays unchanged.
- Windows may still request administrator approval. Verification or session-save failures stop the update; unattended setup never forcibly terminates a busy Pulse window.
- This flow is available from this client version onward. Updating from an older client still uses that client's update entry point. Portable copies continue to update through the new ZIP.
