# 鹿铃 0.5.10

这一版重做了标签页的活动态配色，并把多窗口管理搬进了标题栏。

## 标签页

- 活动标签改为从顶部向下渐隐的主题色渐变，默认「海洋蓝绿」，底部两端的尖角已去掉。
- 设置 › 标签页与窗口 新增「活动标签渐变」：18 套预设配色，外加「自定义」——开始、过渡、结束三种颜色可以只设其中一项，也可以全部设置，渐变会按已设置的颜色均匀分布。
- 窗口失焦时，活动标签的渐变、描边与底部指示条自动隐藏，回到普通底色。
- 渐变浓度降到顶部 30%，到底部完全透明。

## 窗口管理

- 标题栏右侧、设置/外观按钮旁新增窗口管理按钮（关闭单窗口模式后显示）。
- 菜单包含：新建窗口、窗口总览、标签页移到新窗口，以及 3×3 的窗口排列面板——左右并排、上下堆叠、三列排列、平铺、主次排列、层叠、主窗在右、主窗在上、合并窗口。
- 排列按显示器工作区计算，考虑窗口间隙与最小尺寸；按住 Shift 会把每个显示器上的窗口分别排列。
- 菜单标题行显示当前窗口与标签数量，底部给出 Shift 提示与「至少打开两个窗口」提示。

## 工具栏与列表

- 「排序」改用与「分组」一致的鼓轮选择器。
- 「分组」按钮在所有列表视图（含此电脑、搜索结果、标签、回收站）中显示，不再只限于普通文件夹。
- 设置 › 文件列表 的缩略图缓存改为显示占用进度条与「已用 X MB / 512 MB」。
- 修复右下角状态栏提示文字与「全部快捷键」按钮重叠的问题。
