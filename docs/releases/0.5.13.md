# 鹿铃 0.5.13

这一版继续修右键菜单的卡顿。

## 右键菜单

- **不再加载系统的「发送到」处理器**。它每次都会在自己的查询里卡住约 0.9 秒，把整个菜单的等待预算吃光，还留下一个永不退出的线程。代价是右键菜单里不再有「发送到」子菜单。
- 菜单会话在关闭后最多保留 **30 秒**（原来 120 秒）。之前每右键一次就把三十来个处理器线程和它们的扩展 DLL 留在进程里两分钟，连着右键几次宿主就明显变慢。

## 实测对比

| 指标 | 修复前 | 修复后 |
| --- | --- | --- |
| 单次右键耗时 | 406–1063 ms | 47–141 ms |
| 右键菜单项数 | 5–10 | 16–37 |
| 处理器超时告警 | 每次 | 无 |
