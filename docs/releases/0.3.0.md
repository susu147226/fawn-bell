# 鹿铃 0.3.0 · 手机拖动、同名询问与刷新

这一版把手机（MTP）的文件操作补齐，并修掉了几个刷新和占用问题。

## 手机拖动

- 手机内部拖动：默认移动，按住 `Ctrl` 复制。
- 手机 ↔ 本地：默认复制，按住 `Shift` 移动。
- 从资源管理器、桌面或浏览器拖文件进手机文件夹。
- 把手机文件拖到桌面、资源管理器或其它程序。

## 同名文件询问

拖动复制或 `Ctrl+C` / `Ctrl+V` 时，如果目标已有同名文件，会先询问：

- **复制并替换**
- **不要复制**

适用于手机↔手机、手机↔本地、本地↔手机、本地↔本地。选择替换时会等旧文件真正从设备消失后再复制。

## 刷新

- 手机插拔后，左侧栏立即出现或移除设备。
- 浏览器或其它程序删除文件后，当前目录 1 秒内刷新。
- 复制、剪切、拖动完成后，源目录和目标目录都会刷新。
- 从浏览器打开下载目录时，自动高亮刚下载的那个文件。

## 删除更顺畅

- 文件图标改为按扩展名获取，不再让 Shell 打开文件内容。
- 刚写入的文件暂时跳过缩略图生成，避免和浏览器的删除操作争抢文件。
