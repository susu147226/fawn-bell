### 浏览与列表

- 改名或新建后不再立即重新排序：改名的项目留在原位并保持选中，新建的文件或文件夹出现在列表末尾；按 F5、切换排序或重新进入文件夹时再按规则排列，选中项会跟着移到新位置。
- 每个文件夹分别记住排序方式；新增“将视图和排序应用到所有文件夹…”，一次统一所有文件夹（分组方式不受影响）。
- 详细信息视图新增“创建日期”和“访问日期”列。右键列标题可以选择显示哪些列或恢复默认列，也可以按这两列排序和分组。
- “此电脑”中的磁盘显示类型（本地磁盘、移动磁盘、网络驱动器、CD 驱动器、RAM 磁盘），不再显示 1601-01-01 的日期。

### 启动与标签页

- 设置 → 通用 → 启动与关闭新增以下选项：
  - 默认位置（某个文件夹或“此电脑”）；
  - 启动时打开：上次的标签页，或只打开默认位置；
  - 新标签页打开：当前文件夹，或默认位置。
- “启动时打开”选择默认位置时，从托盘恢复窗口也会回到默认位置。
- 通过文件路径启动 Pulse 时（例如把 Pulse 设为默认文件管理器后“打开所在文件夹”），会同时选中这个文件，而不只是切到它所在的文件夹。

### 搜索与地址栏

- 快速搜索（Alt+Space）中按 Shift+Enter 或点击底部的“在主界面搜索”，可以带着同样的关键词、搜索方式和范围转到主窗口，在新标签页中查看全部结果；返回即回到原文件夹。
- 地址栏输入 cmd、powershell、pwsh 或 wt，可以直接在当前文件夹打开终端。

### 右键菜单

- 可以显示 Windows 11 新式右键菜单项，例如 WinRAR 7、NanaZip、VS Code、Bandizip、Windows Terminal 的菜单项。
- 设置 → 本地右键菜单新增“Pulse 自带项”，可以隐藏 Pulse 自己的右键命令（如标签、全选 / 反选）和文件行按钮。
- 右键菜单、下拉菜单和命令面板的行高跟随“列表行高”：紧凑 / 标准 / 舒适分别对应 30 / 36 / 40 像素，默认外观不变。
- 修复过长的菜单项文字被截断却没有省略号的问题；文字显示不全时，悬停可以看到全文。

### 界面

- 左侧栏滚动条平时隐藏，滚动时出现，鼠标移到滚动条上时变宽，方便拖动。
- 快捷键帮助列出全部快捷键，按导航、文件、搜索、选择、标签页与分栏分组显示；修复从状态栏“全部快捷键”打开时一闪而过的问题。
- 修复窗口右上角出现第二组重影按钮的问题。标题栏右键不再弹出系统菜单。

### 修复

- 打开文件或批处理时，以文件所在的文件夹作为工作目录。
- 快速访问中项目的标记在重启后不再丢失。
- 修复高级搜索、批量重命名对话框中的输入框有时不显示文字、无法再次点中的问题。
- 项目采用 Apache-2.0 许可证。

提供 Windows 10/11 x64 安装版、Windows 8.1 兼容版和免安装版。不同系统的预览组件和视觉效果可用性可能不同。
