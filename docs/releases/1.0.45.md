### 快速预览

- 按空格即可预览，预览窗口全面升级：Markdown 按排版显示，代码语法高亮，文件夹显示内容列表，PDF 可逐页翻看，音频显示封面和波形。
- 新增表格预览：CSV / TSV / XLSX 以表格显示，固定表头和行号，支持单元格选择、查找和切换工作表。
- 新增结构化数据预览：JSON / XML 显示为可折叠的树，Jupyter Notebook（.ipynb）按单元格显示。
- 新增文档预览：DOCX 无需安装 Office 即可阅读正文；EPUB 带目录、按章阅读，可在全书中查找。
- 视频预览新增播放控制条：播放/暂停、进度拖动、逐帧、音量与倍速。缺少系统解码器（如 HEVC、AV1）时会提示并可直接前往 Microsoft Store 获取。
- 图片预览：动态 WebP 和 APNG 可播放；ICO / CUR 图标可切换各个尺寸；HEIC / AVIF 缺少系统扩展时给出获取提示。
- 设置 → 常规新增“快速预览 · 支持的格式”，按类别列出所有可预览的格式，并检测 HEIF / HEVC / AV1 / WebP 系统扩展是否已安装。

### 暂存盘

- 新增文本对比窗口：暂存盘比较两个文本文件时，点击“查看差异”或在批量菜单选择“对比这两个文件”即可打开。支持并排/统一视图、行内字符差异高亮、仅显示差异、忽略空白和大小写、左右交换、F7/Shift+F7 跳转、缩略条定位和复制选中内容，并显示编码与换行符。
- 暂存盘新增比较模式，可对照两个项目的位置、修改时间、大小与内容是否相同；二进制文件会单独标注。
- 已移动或删除的暂存项会提示失效，可一键移出。
- 批次可切换复制或移动：拖放默认复制，按住 Shift 为移动；复制批次在放下后仍保留。整个暂存盘可一次拖出到目标位置。

### 浏览与搜索

- 新增列表分组：可按名称、日期、类型或大小分组，工具栏常驻“分组”按钮，每个文件夹分别记住设置；下载和最近默认按日期分组。
- “分组”和“排序”改用滚轮式选择器，右侧实时预览效果。
- 新增双栏文件夹对比，快速标出两侧不同、缺失和较新的项目。
- 重新设计地址栏搜索：搜索框更宽，筛选标签不再截断，提示样式统一。
- 改进高级搜索交互，并保留搜索条件与状态。
- 鼠标中键在后台标签打开文件夹，Ctrl+中键在前台标签打开；重复打开同一文件夹时切换到已有标签。

### 界面与体验

- 窗口最小化、最大化加入过渡动画。
- 新增上下文操作提示，帮助发现快捷键和隐藏功能，可在设置中关闭或重置。
- 文字渲染新增“自动 / 清晰 / 平滑”三种模式。
- 修复输入框光标显示问题，以及其他稳定性与细节改进。

提供 Windows 10/11 x64 安装版、Windows 8.1 兼容版和免安装版。不同系统的预览组件和视觉效果可用性可能不同。
