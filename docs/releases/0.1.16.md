# 鹿铃 0.1.16

## 批量重命名：默认按扩展名分组编号（对齐 rename.py）

作者给的 `rename.py` 的规则是：**按扩展名分组、组内按自然顺序排序、每组各自从 0 编号**，
名称形如 `前缀_序号 + 扩展名`。这样不同扩展名的文件可以共用同一个名字：

```
date_0.png  date_1.png  date_2.png
date_0.jpg  date_1.jpg
date_0.txt
```

以前只有右键菜单里的「按序号重命名（从 0/1 开始）」才会分组，普通「批量重命名」是**整体连续编号**，
于是 `.png` 和 `.jpg` 会拿到不同序号（`date_0.png`、`date_1.jpg`），达不到上面的效果。

现在**简化模式下默认就按扩展名分组**：在「新名字」框里输入前缀（例如 `date`），
同扩展名的文件各自从 0 开始编号，不同扩展名共用同一个名字。

- `LulingSetup-0.1.16.exe`
- `Luling-0.1.16-portable-win-x64.zip`
