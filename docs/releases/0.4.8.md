# 鹿铃 0.4.8 · 时间卡片动效与节日补充

这一版打磨标题栏时间卡片，并扩充节日与纪念日。

## 标题栏时间卡片

- 三页切换改成上下滚动：旧页向上滑出、新页从下方滑入，320ms 缓动；动画期间临时提高刷新率，滚动更顺。
- 单击卡片可以手动切换到下一页，自动轮播照常；切换后重新计时。
- 右键卡片直接打开日程面板。
- 第一页改为两侧对齐：时间和星期贴左，日期和农历贴右。
- 悬停提示补充了操作说明。

## 节日与纪念日

新增：

- 花朝节（农历二月十二）、寒食节（清明前一天）
- 中国农民丰收节（秋分当天）
- 母亲节、父亲节、感恩节（按“第几个星期日/四”计算）
- 中国纪念日：学雷锋纪念日、消费者权益日、国家安全教育日、防灾减灾日、世界环境日、抗战胜利纪念日、九一八纪念日、烈士纪念日、国家宪法日、国家公祭日

「距离下一个节日」的倒计时现在也会把这些日子算进去。
