### Shortcuts and file lists

- Shortcuts, URL files, symbolic links and junctions use a circular arrow badge. Hovering or selecting expands it to show the destination. (#88)
- Medium and large icons keep the badge inside the artwork without adding a line or increasing the filename gap. Destination text is truncated within narrow items.
- Fix context-menu tools that require administrator privileges failing to launch; Windows elevation confirmation is preserved. (#86)
- Add smaller, standard, larger and largest interface text sizes in Settings.

### Indexing and resource usage

- Reduce repeated work in index maintenance, folder-size aggregation and change summaries.
- Fix index corruption caused by replaying an incremental log against an incompatible snapshot. Invalid caches are rebuilt rather than repeatedly attempting failed aggregation.

### Diagnostics

- Add navigation, file-operation, update and indexing events, plus CPU, memory and handle samples to help investigate reported problems.
- Diagnostic exports include size-limited runtime logs and collection results. Logs rotate automatically and do not record file contents.
