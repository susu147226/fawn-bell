# 鹿铃 0.1.11

## 装不上：找到了真正的根因

作者提供了决定性的事实：**官方发布的 Pulse 安装包能装，而我这边构建出来的 Pulse 包也装不上**。
Pulse 源码我一行没改，所以问题只可能在本机的打包产出上。

对比两个包：官方包**不含** `PULSEPK1` 魔数——说明**官方根本不用仓库里的这套自解压方案**。而这套方案
（`pack_installer` + stub）的问题在于：

**stub 是 `asInvoker`，却要在获得提权之前先把 payload 解压到目标目录**。安装目录（不论是
`C:\Program Files` 还是 `%LOCALAPPDATA%\Programs`，后者是提权装进去的、ACL 只授权管理员）都写不进去，
于是解压被拒绝，安装根本起不来。`setup_main.cpp` 里那段"未提权就自我提权"发生在**解压之后**，
救不了这一步。

之前我曾把这里设成 `requireAdministrator`，但当时和 `setup.manifest` 里的同名声明冲突、编译失败，
就退回 `asInvoker`——那是个错误决定。

本版把 stub 改为 **`requireAdministrator`**：**安装包一启动就请求管理员权限**，解压与安装全程持有
提权令牌。

## 安装

- `LulingSetup-0.1.11.exe` —— **启动时会弹 UAC，请允许**
- `Luling-0.1.11-portable-win-x64.zip`
