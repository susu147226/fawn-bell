# 鹿铃 0.5.9

这一版把界面的图标、配色和列表细节整体重做了一遍，同时给扩展商店补上了签名与审核，并让打开/保存对话框全部换成鹿铃自己的实现。

## 界面

- 整套命令图标换成新的双色绘制：未选中时单色，选中或多选后显示语义色，状态栏、工具栏、分栏切换和右键菜单保持一致。
- 状态栏新增五个分栏按钮（单栏、左右、上下、三栏、四宫格），鼠标悬停时淡入预览将要使用的布局。
- 文件列表的复选框改成新的规则：表头常驻，行首在悬停、选中或多选时才显示，勾选样式与间距重做。
- 文件树的分支箭头单独留出点击区，与复选框拉开间距。
- 修改时间标记重做：徽点为五种形状，时间条按范围内剩余时间给出长度；配色提供六套方案，其中「主题色」会跟随自定义颜色。
- 主题色支持直接输入色值；配色方案在设置里按真实色序展示，并随标记方式切换示意图形。

## 扩展商店

- 商店目录改为签名清单：`index.json` 由内置公钥验签，离线回退同样要重新验签。
- 发布者身份绑定公钥指纹；首次安装某个发布者的扩展前会单独确认，信任记录保存在本机。
- 安装顺序固定为目录签名、包大小与 SHA-256、清单哈希、发布者签名、id 与版本核对，最后才原子替换目录。
- 商店页改为三列卡片网格，新增分类过滤（全部、压缩包、预览、搜索、AI、其他）和「从文件安装…」。
- 仓库里加入目录审核与签名工具（`tools/extensions`）以及目录检查工作流。

## 打开与保存

- 打开和保存都交给鹿铃自己的选择器：另存为模式会补全扩展名、拒绝非法名称，目标已存在时先提示、再次确认才覆盖，只读文件直接拒绝。
- 标签的导入与导出不再调用系统文件对话框。
