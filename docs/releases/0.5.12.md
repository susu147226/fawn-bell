# 鹿铃 0.5.12

这一版修的是右键菜单的响应速度。

## 右键菜单

- 菜单不再等待所有第三方扩展：第一份快照到达（约 80–100 ms）就弹出，其余菜单项随后自动补齐。
- 修复 0.5.11 引入的回归——首次快照还没有内容时，菜单会空等到超时。
- 打开过的目录和文件类型，右键时直接用上次的布局立即显示。
- 卡死判定上限回到 900 ms，并且仍然只把「确定独自卡住」的扩展上报；已经返回但耗时较长的扩展不再被误判。

## 关于第三方菜单项

上一版把部分第三方扩展误判成超时并写进了禁用列表。如果更新后仍然看不到某些第三方菜单项（例如网盘、迅雷），那是配置里的禁用记录，不是程序缺陷——在右键菜单的设置里重新启用即可。
