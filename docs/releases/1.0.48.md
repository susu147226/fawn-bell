国庆版：新增繁體中文界面。

### 繁體中文

- 新增繁體中文界面，采用台湾常用词汇（如「檔案總管」「資源回收筒」「捷徑」）。系统语言为繁体中文（台湾、香港、澳门）时自动启用，也可以在“设置 → 显示语言”中选择。
- 繁体界面使用 Microsoft JhengHei UI 字体；安装程序新增繁体中文。
- 适配繁体 Windows 的右键菜单分类和文件操作错误提示；搜索中的 kind: 筛选支持繁体关键字。

### 修复

- 英文界面的文件大小提示中误显示中文单位。
- 命令菜单搜索框的提示文字现在跟随界面语言。
- 切换简繁体后，预览格式说明会立即刷新。

提供 Windows 10/11 x64 安装版、Windows 8.1 兼容版和免安装版。
