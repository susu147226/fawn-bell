Feature and bug-fix release: more issues reported on GitHub.

### Context menu

- Menus taller than the screen no longer run off the bottom: they stay on screen with scroll arrows at the top and bottom. Rest on an arrow to keep scrolling, click it to page, or use the mouse wheel or the arrow keys. (#67)
- Shell items such as New or archive tools that arrive after a context menu opens are added to the open menu, so a second right-click is no longer needed. (#73)

### Search

- Filename searches in a network folder (UNC path) that is not in the network index now walk the folder live and stream results instead of returning nothing. A banner offers "Add to network index" for faster searches later. (#74)

### File list and grouping

- The group menu and the group wheel have "Apply grouping to all folders…". After a confirmation every folder, including ones never opened, uses that grouping and earlier per-folder choices are cleared; a folder can still be set on its own afterwards. Recent, search results, tags and the Recycle Bin keep their own grouping. (#75)
- New "Confirm before deleting" setting (off by default): Delete asks before moving items to the Recycle Bin. Permanent deletes always ask. (#71)

### Notification area

- Settings → Startup & shutdown has a "Notification area icon" choice: Always, In background or Never. With Never, Pulse can still keep running after its window is closed; open Pulse again to bring the window back. The command palette (Ctrl+Shift+K) now offers "Exit Pulse". (#57)

### Install and update

- Upgrading from an older version first lets a running Pulse, including one closed to the tray, save its tabs and layout and exit, then installs silently over the existing location instead of stopping with "Pulse is busy". Copies or moves in progress are allowed to finish first and are never interrupted.

Available as Windows 10/11 x64 and Windows 8.1 installers, plus a portable Windows 10/11 x64 ZIP.
