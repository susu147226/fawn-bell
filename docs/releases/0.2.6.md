# 鹿铃 0.2.6 · 更新提示不再错过

一个小补丁，只改了一件事：**检查更新失败后会重试**。

以前如果某次检查没能拿到结果（网络一时不通、代理没起来、GitHub 抖了一下），
下一次检查同样要等到 **六小时后**。如果你的电脑每天只开两三个小时，或者网络在
开机那会儿还没就绪，就可能**一整天都收不到更新提示** —— 只能自己去设置页点
「检查更新」。

现在：**检查真正完成**（无论有没有新版本）才等六小时；**没拿到结果**则 **15 分钟
后重试**，网络恢复后自然就检查到了。

如果你的某台电脑**仍然**没有收到更新提示，麻烦把这份日志发过来：

```
%LOCALAPPDATA%\Luling\Diagnostics\Runtime\app-*.jsonl
```

里面 `update_check_start` / `update_check_end` 两行就能说明是哪一步没走通。
