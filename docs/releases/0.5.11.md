# 鹿铃 0.5.11

这一版重做了右键菜单的等待策略，修好了第三方右键项时有时无、菜单要等很久才出来的问题。

## 右键菜单

- 菜单不再等所有第三方扩展：谁先完成谁先显示，之后每 60 ms 补一次，慢的扩展不再拖住整个菜单。
- 之前超过 900 ms 没返回的扩展会被当成「卡死」并永久禁用——这是 WPS、网盘、输入法这些菜单项无故消失的原因。现在只在「其余扩展全部完成、只剩它一个没返回」时才判定，判定上限也放宽到 5 秒。
- 「发送到」在构建默认菜单时会持有加载器锁，此时还在加载 DLL 的扩展不再被误判为卡死。
- 已经完成、只是耗时较长的扩展不再上报，不会再因为一次慢右键被永久停用。

## 稳定性

- 第三方扩展卡死时，宿主进程的内存回收改为按占用触发：超过 256 MB 且无会话时自动重启，避免长时间使用后涨到 GB 级。
