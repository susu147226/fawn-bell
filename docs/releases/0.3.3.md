# 鹿铃 0.3.3 · 多窗口与文件操作体验

这一版把多窗口补齐并打磨了文件操作的落点：移动、重命名之后不用再自己找文件。

## 多窗口

- 新建窗口：`Ctrl+N`、右键「在新窗口打开」、按住 `Shift` 双击文件夹。
- 把标签拖到另一个窗口的标签条即可并入；只有一个标签的窗口这样拖，两个窗口直接合并。
- 把窗口拖到另一个窗口的标签条：目标标签条亮起并显示插入位置，松开合并；按 `Esc` 取消。
- 「合并所有窗口」（`Ctrl+Shift+J`），合并后可点提示撤销，窗口和标签按原样恢复。
- 关闭多个窗口中的一个时，它的固定标签会交给仍开着的窗口，重启后不再丢失。
- 重启后恢复全部窗口、位置、标签与各自的撤销历史。
- 标签排满标签条时，按住 `Alt` 拖动标签即可移动窗口。

## 文件操作

- 移动文件后，新文件按当前排序就位，不再堆在列表末尾。
- 重命名或移动完成后，结果会自动选中并滚动到可见位置。
- 批量重命名入口只保留一项；打开时光标在新名字输入框，按 `Tab` 到序号栏直接输入即可替换。

## 性能与稳定性

- 最小化或收进托盘时，后台轮询从 0.2 秒放宽到 1 秒；窗口被其他虚拟桌面遮挡时停止动画帧。
- 退出时先撤托盘、保存会话、收尾文件操作并释放单实例，再停止后台服务；若 2 秒仍未退出会记录并结束进程，不再留下看不见的常驻进程。
