# 鹿铃 0.4.5 · 预览进程回收、切换缓存与内存优化

这一版减少快速预览在后台常驻的进程，消除树 / 源码切换时的停顿，并降低整体内存占用。

## 内存与进程

- 预览宿主通道空闲 60 秒后自动结束对应进程，不再按 CPU 核心数常驻；下一次预览再自动拉起。
- 预览并发按位置自适应：本地磁盘 8 路，网络共享与可移动磁盘 4 路，移动设备 3 路；切换目录时自动增减，不必重启。
- 缩略图缓存预算从列表 96 MB / 详情 48 MB / 悬停 32 MB 降到 24 / 16 / 12 MB，仍各自独立。
- 窗口最小化时释放工作集：后台内存从约 130 MB 降到约 30 MB，恢复窗口后按需换入。
- 网格缩略图默认预算与缓存条目数同步下调。

## 快速预览

- 树 / 源码切换增加了一份“另一侧”的文本布局缓存，切回时直接复用，不再重建整段文本，切换停顿消失。

## 包含 0.4.4 的修复

- 代码与纯文本预览完整显示到 1 MiB，不再只显示前 12000 字符。
- 预览顶部的树/源码切换、位置计数、箭头与复制按钮按实际宽度排布，不再重叠。
- 文件名按粗体实际字宽测量，单列详情使用整行宽度，不再无谓省略。
