# 鹿铃 0.4.5 · 预览进程回收与切换缓存

这一版减少快速预览在后台常驻的进程，并消除树 / 源码切换时的停顿。

## 快速预览

- 预览宿主通道空闲 60 秒后自动结束对应进程，不再按 CPU 核心数常驻。后台的 `Luling.Preview.exe` 从二十多个降到个位数，下一次预览会自动重新拉起。
- 树 / 源码切换增加了一份“另一侧”的文本布局缓存，切回时直接复用，不再重建整段文本，切换停顿消失。

## 包含 0.4.4 的修复

- 代码与纯文本预览完整显示到 1 MiB，不再只显示前 12000 字符。
- 预览顶部的树/源码切换、位置计数、箭头与复制按钮按实际宽度排布，不再重叠。
- 文件名按粗体实际字宽测量，单列详情使用整行宽度，不再无谓省略。
