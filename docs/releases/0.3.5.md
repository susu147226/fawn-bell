# 鹿铃 0.3.5 · 右键菜单恢复第三方软件图标

这一版把系统右键菜单里第三方软件和扩展的图标补齐，和资源管理器显示的一致。

## 右键菜单

- 解压、Git、Visual Studio、VS Code、WPS、网盘、云同步等第三方菜单项重新显示各自的图标。
- 系统自带的菜单项（包含到库中、以便携式设备方式打开等）也带上图标。
- 程序图标为旧式掩码格式时不再画不出来；注册表图标路径读取的一个多余字符也已修正。
- WPS 的菜单项统一显示 WPS 品牌图标（其扩展本身不提供图标资源）。
- 扩展自身没有图标、或注册项指向已删除程序的菜单项保持无图标，与资源管理器一致。
