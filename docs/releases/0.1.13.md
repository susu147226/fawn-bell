# 鹿铃 0.1.13

## 地址栏历史下拉：宽度与地址栏对齐

上一版把它放宽到地址栏的 1.8 倍（最少 560），实际看起来过宽、和输入框脱节。现在**与地址栏等宽**。

## 批量重命名：更多选项移到「取消」旁边

「更多选项」按钮从标题下方移到**底部「取消」左侧**，不再压着「新名字」标签。展开后的
查找 / 替换 / 补零 / 只改扩展名等字段**只在点击后才参与布局**，默认的简洁形态不受影响。

## 安装

- `LulingSetup-0.1.13.exe`
- `Luling-0.1.13-portable-win-x64.zip`

**注意**：请把安装包**复制到桌面等普通目录**再运行——从本会话工作目录启动会继承沙箱上下文，
写 `%TEMP%` 与安装目录都会被拒。
