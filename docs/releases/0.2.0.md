# 鹿铃 0.2.0 · 我学会变身啦

好久不见，这次带来的不是修修补补，是一件我以前做不到的事。

以前的我只会「看」：把图片铺在预览里、把视频放出来给你瞧。看归看，文件本身还是老样子。
现在不一样了——**我可以把文件变成别的样子**。

在任意文件上按右键，会多出一个「转换」小菜单：

## 转换格式

图片、音乐、视频都能换壳。攒了一堆 PNG 想换成 JPG？iPhone 拍的 HEIC 别人打不开？
MKV 里的视频想倒进 MP4？交给我。

图片这边：`jpg` `png` `webp` `bmp` `gif` `tiff`
视频和音乐：`mp4` `mkv` `webm` `mov` / `mp3` `m4a` `flac` `opus` `wav` `ogg`

## 调整尺寸

图片和视频都能改大小。选个 1920×1080，竖着的图我不会硬拉扁——按比例来，多出来的边留白。

## 压缩

图片给了**四档**，随你挑：

| 档位 | 适合什么时候 |
| --- | --- |
| 无损 | 一个像素都不想动，只是想让它小一点 |
| 轻度 | 看得出来的差别？不存在的 |
| 中度 | 平时发个图、存个档 |
| 强力 | 就想让它小到能塞进任何地方 |

（小提示：无损档我只对本来就是无损的图（PNG、BMP、TIFF）做，JPEG 这种本来就是有损的，
我不会假装能「无损」，会老老实实告诉你做不了。）

视频压缩也分了档，走的是画质阶梯。

## 动手之前，先给你看清单

不管选哪一项，我都会先把结果列出来：哪个文件会变成什么名字、哪个格式我不认识、
哪个是云端还没下载下来的、哪个是只读的系统文件。你看过、点头，我才动手。

**原文件留不留，也由你说了算**——默认留着，绝不偷偷替换你的东西。

---

## 得先给我装个小引擎

转码这件事我自己干不了，得请 FFmpeg 帮忙。所以第一次用「转换」的时候，我会问你要不要
下载**转换引擎**（大约 36 MB）。跟之前那些预览增强包一样，装了才下、随时能卸、卸了干净。

有件事得说清楚，免得以后你被人问住：这个引擎里用了 H.264 / H.265 编码，带着 GPL 的组件，
所以**它自己是 GPL 授权的**（其他预览增强包都还是宽松许可）。不过我只把它当成一个
**外部小程序**来使唤，没把它缝进我身体里，所以鹿铃本体不受影响。源码怎么拿、许可证全文，
都随包一起带着。

## 不想看见它？

「设置 › 右键菜单」里把「转换」那一行关掉，菜单立刻就干净了。设置页「预览增强包」里
也能随时把它卸掉。

## 下载

| 产物 | 说明 |
| --- | --- |
| `LulingSetup-0.2.0.exe` | 标准版，需要时再下引擎 |
| `LulingSetup-0.2.0-full.exe` | 含全部预览增强包，装完即用 |
| `Luling-0.2.0-portable-win-x64.zip` | 免安装版，含全部预览增强包 |

**装之前记得先把安装包复制到桌面这类普通目录再双击。**
