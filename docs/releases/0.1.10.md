# 鹿铃 0.1.10

## 构建 ID 不再固化

`LULING_BUILD_ID` 首次生成后会写进 `build/luling_build_id.txt` 并在之后**每次构建复用**，
所以它一直停在 `20261013T071234Z`——**不能用来判断代码新旧**，这也让前几轮排查失去了一条线索。

本版重置了它：关于页的「构建时间 / 构建 ID」现在反映真实构建时间。请用它确认手里的构建：
**构建时间应当是 2026-10-14**。

## 安装

- `LulingSetup-0.1.10.exe`（已恢复上游的自我提权逻辑）
- `Luling-0.1.10-portable-win-x64.zip`
