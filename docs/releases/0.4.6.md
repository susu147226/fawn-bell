# 鹿铃 0.4.6 · 空格预览与索引内存

这一版修复第一次空格预览会闪退的问题，并降低全盘索引的内存占用。

## 快速预览

- 修复第一次按空格预览时窗口闪一下就消失、要按第二次才打开：打开预览后，空格键的自动重复会作为新的按键送到刚获得焦点的预览窗口，而空格在那里表示关闭。
- 现在忽略带“自动重复”标记的空格，以及窗口显示后 200 ms 内的空格；之后按空格仍正常关闭。
- 修复与文件类型无关。doc 等加载较慢、按键更久的场景最容易遇到，图片和文本通常来不及触发。

## 索引与内存

- SQLite 写缓存从 32 MB 降到 8 MB。
- 搜索快照的 `mmap` 上限从“可用内存的一半（最多 16 GB）”降到 32–128 MB，避免大数据库被整段映射进工作集。
- 全盘秒搜保持不变；索引服务需要安装新版后重新启动才会使用新的预算。
