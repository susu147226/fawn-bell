# 鹿铃 0.4.0 · 文件树、预览窗格重做与共享服务器修复

这一版新增列表内文件树，重做预览窗格与快速预览，并集中修复共享服务器（UNC）与移动设备的读写问题。

## 文件树（新）

- 详细列表中的文件夹可以展开：列表内显示子项，带展开箭头、缩进和层级参考线，修改时间/类型/大小列照常显示。
- 设置 → 文件列表 → **文件树** 开关，默认开启，可随时关闭。
- 子文件夹在后台线程按需枚举，展开不卡界面；再次展开会刷新一次，保证折叠期间的变化能看到。
- 展开后的子文件夹只读浏览：**单击即打开**进入该文件夹。
- 外部程序在已展开的子文件夹里新增、删除、重命名文件后，约 2–5 秒内自动反映到树里，无需折叠或按 F5。
- 只在详细列表生效；搜索、标签、回收站、分组视图自动按普通平铺显示。

## 预览窗格与快速预览（重做）

- 页眉：文件名 + 类型/尺寸/大小/修改时间，右侧位置计数（如 4/5）、前后切换，以及“用 X 打开”按钮。
- 页脚：格式信息与「适应/缩放、背景、图片信息、旋转」快捷操作。
- 图片信息抽屉：尺寸、格式、透明、位深等属性、大小、修改时间，以及 RGB 直方图。
- 透明图片自动棋盘格；不透明图片不再出现深浅闪烁的垫底。
- 打开方式改为分体按钮：点文字直接用默认应用打开，点右侧箭头弹出选择菜单（默认应用、系统中注册的其他应用、选择其他应用…），菜单项使用各应用自己的图标。
- 修复真实鼠标点击标题栏按钮无响应的问题（按钮此前落在窗口拖动区域）。
- 修复视频快速预览只显示单帧（此前调试崩溃触发安全模式，安全模式会禁用视频播放）。
- 修复视频放大/全屏后画面横向错位的问题。
- 缓存文件类型的系统关联信息，连续浏览同类型文件时预览打开更快。

## 共享服务器（UNC）

- 修复在共享路径上新建、重命名、删除、复制、移动偶发失败：瞬时网络错误自动重试，必要时重新建立共享连接。
- 修复外部程序把文件保存到共享目录后，鹿铃不显示新文件（共享目录定时检查补上通知遗漏）。
- 修复复制到共享路径时报“系统找不到指定的路径”：目标目录逐级创建，长 UNC 路径也能处理。
- 已用真实 UNC 路径（`\\172.16.0.239\ppd\cyx`）实测：服务器→本地、本地→服务器、服务器内部新建/重命名/移动/删除均正常。

## 移动设备

- 设备内的文件夹和文件改用与本地一致的标准图标，不再显示电脑图标。
- 修复设备内文件“无法打开/预览显示无法读取”：预览宿主现在能识别设备路径并让系统直接读取设备文件。
- 设备照片的网格缩略图、快速预览（含大图）与双击打开均已验证。

## 新建菜单

- 不再只依赖系统注册表：新增内置 Word、Excel、PowerPoint、RTF、CSV、PSD、联系人、ZIP 等类型。
- 每一项使用已安装程序的真实图标。

## 外观与操作

- 设置 → 外观 → 主题色支持自定义：HSL 滑块、色板与十六进制输入，实时生效。
- 新增自定义工具栏面板：工具/选中时/应用 三类命令、搜索、固定命令，快捷键 Ctrl+/。
- 新增“管理标签”对话框（全部/常用/未使用/有失效项、多选、合并、删除）与侧栏“所有标签”。
- 列表内新增“滚动时固定上级文件夹”行和 SVN 工作副本状态标记。
- 文件列表支持复选框多选。
- 移动设备、网络位置等位置继续使用统一的新建/打开流程。

## AI 助手

- 设置页按类别重做；每个模型服务独立保存 API Key，可手动选择默认模型并做连接探测。
- 对话内容持久化，重启后可继续。
- 并发请求与撤销记录按客户端隔离。

## 缩略图

- 并行道按素材量自适应：最少 3 条，上限随 CPU 核数扩展（最高 32）。
- 刚写入的文件立即生成缩略图，不再等待。

## 稳定性

- 修复新增文案 id 超过本地化表上限导致界面出现空白文字（设置项、图片信息抽屉等）。
- 修复构建目录头文件依赖缺失导致的构建产物不一致与启动崩溃。
