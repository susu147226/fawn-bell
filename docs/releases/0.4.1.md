# 鹿铃 0.4.1 · AI 助手修复与增强包接线

这一版集中修复 AI 助手设置、密钥输入、聊天输入与模型菜单的问题，并把「增强包」页的下载状态真正接通。

## AI 助手连接与密钥

- 修复设置页 API Key 输入框被主界面合成层盖住：选中后看不到文字、光标和粘贴结果。密钥与接口地址改用与地址栏相同的重定向编辑面。
- 修复一次 Ctrl+V 会粘贴两份密钥：Ctrl+V 同时触发了自定义粘贴和控制字符粘贴，现已去重。
- 密钥显示统一为固定 10 个圆点，不再显示首尾字符，也不暴露密钥长度。
- 打开密钥框时不再载入已保存的密钥，粘贴是替换而不是追加；留空关闭则保留原值。
- 接口地址文字本身即可点击修改，不必只依赖「更改」按钮。
- 修复输入框隐藏后再次点击不显示的问题（位置未变时没有重新显示窗口）。
- AI 助手面板里的「管理连接」卡片同步修复：地址可编辑、密钥同样全遮挡、粘贴路径一致。

## AI 助手聊天

- 修复聊天输入框无法显示输入内容：输入框改为重定向编辑面，文字、光标与选中都可见。
- 聊天输入框中的中文按原字号的 85% 绘制，英文与数字保持原字号；光标、选中和点选位置不错位。
- 模型切换菜单：
  - 点击面板内其他位置、面板外任意位置或按 Esc 都能关闭；
  - 修复菜单淡出到一半停止刷新、在输入框后面留下残影的问题。
- 「添加文件」现在先选择「添加文件…」或「添加文件夹…」：
  - 文件支持多选，最多 20 个；
  - 文件夹只写入路径，不递归枚举，大目录也不会卡住。
- 标题栏新增垃圾桶按钮「清空聊天记录」，与「新对话」并排；清空前弹出确认框，默认焦点在「取消」。
- 修复发给 DeepSeek 时返回 `400 Invalid schema for function`：工具定义中的 `description` 被错误导出成布尔值 `true`，现已全部输出为字符串。

## 增强包

- 「设置 → 增强包」页现在读取真实的增强包状态，安装、更新、卸载按钮与徽标均可用（此前只有「快速预览」页读取状态，导致增强包页按钮不可用）。
- 「快速预览」页移除整套增强包卡片，只保留预览方式、格式支持与系统解码器。
- 媒体来源（内置 FFmpeg / 已有 FFmpeg）、自动更新、卸载时清理增强包等设置移到「增强包」页，功能不变。
