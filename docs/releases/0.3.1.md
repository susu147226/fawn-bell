# 鹿铃 0.3.1 · 工具栏、悬停预览与系统右键菜单

这一版新增工具栏、悬停预览和系统右键菜单页，并合入了此前的五项修复。

## 工具栏

- 固定常用命令和软件到工具栏；窗口变窄时，固定项优先收进「更多」。
- 选中文件后工具栏出现操作条：复制、剪切、复制路径、重命名、删除等快捷动作，`⋯` 打开完整菜单。
- 「新建」按钮拆成两段：主按钮直接新建（文件夹或上次的类型），箭头打开新建菜单。
- 「更多」菜单里可以打开「自定义工具栏」，调整新建按钮行为、固定命令和固定的软件。

## 悬停预览

- 默认开启：指针在文件上停留 0.5 秒显示预览卡片，空格仍可打开完整快速预览。
- 卡片支持图片、文本、视频（静音循环）和常见文档，按住 `Ctrl` 临时放大。
- 设置 → 快速预览 中可以切换「悬停预览 / 空格预览」、悬停延迟（0.3 / 0.5 / 0.8 秒）和卡片尺寸。

## 系统右键菜单

- 设置新增「系统右键菜单」页：扫描资源管理器和所有应用的右键菜单项。
- 开关先暂存，点「应用更改」才写入；写入前自动导出 `.reg` 备份，可撤销、全部还原。
- 用户级改动直接写入；机器级改动会请求一次管理员权限。
- 支持按场景筛选、删除残留项，以及只在鹿铃内隐藏某一项。

## 前五项

- 修复向上崩溃、输入法从选区组字、接管后「打开」命令被隐藏、长文件名候选窗位置。
- 图像增强包 1.0.2，支持增量「更新到」和后台自动更新。
- 暂存区重复路径闪烁、筛选框宽度与清除按钮间距。
- SMB 登录提示、取消固定网络位置、无回收站时永久删除、按卷标重命名驱动器、网络发现关闭提示。
- 索引排除系统目录；MFT 读取长文件名与完整目录深度；文件夹大小优先使用索引统计。

## 设备与右键菜单修复

- 手机↔本地复制、拖动不再是「一操作就退出」。
- 同名文件统一使用「替换 / 跳过 / 保留两者 / 应用于剩余 / 取消」窗口，覆盖拖动与粘贴。
- 「保留两者」改为由 Shell 直接以唯一文件名复制，不再经过临时目录。
- 设备传输移到工作线程，拖动和粘贴不再冻结界面。
- 右键第三方项去重与排序持久化；新增内置「压缩为 ZIP」。
