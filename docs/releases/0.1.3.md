# 鹿铃 0.1.3

## 修复：装不上

安装程序改为**用户级安装**，这是这次最实质的改动：

- **默认装在** `%LOCALAPPDATA%\Programs\Luling`——这个位置**不需要管理员权限**，不会再被
  `C:\Program Files` 的写入拒绝挡住。
- **卸载信息写进 `HKCU`**（当前用户），不再依赖 HKLM。
- **开始菜单快捷方式**建到当前用户而不是"所有用户"。
- 因此**不再请求管理员权限**（启动时不会弹 UAC）；如果你手动选一个机器级目录（例如
  `C:\Program Files\...`）而权限不足，会如实报"拒绝访问"，而不是之前那种误导性的
  "找不到路径"。
- 目录创建失败时报告**真实原因**（此前读的是无关调用的错误码）。

## 改进：批量重命名变简单

重命名对话框默认只显示**两样东西**：重命名规则、起始序号，下面是实时预览。

- 查找 / 替换 / 补零序号 / 只改扩展 / 含扩展名 都收进了**「更多选项」**按钮，默认不展开。
- 起始序号框始终可见（以前只在规则里带序号时才出现）。
- 预览区相应变大。

默认规则是 `{n}{ext}`，即 `0.png`、`1.png`……**不补零**。

## 安装
