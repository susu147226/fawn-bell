### Quick Look

- Press Space to preview; the preview window is upgraded throughout: rendered Markdown, syntax-highlighted code, folder listings, page-by-page PDF, and cover art with a waveform for audio.
- Add table previews: CSV / TSV / XLSX show as a table with a pinned header and row numbers, cell selection, find and sheet switching.
- Add structured data previews: JSON / XML as a collapsible tree, Jupyter notebooks (.ipynb) cell by cell.
- Add document previews: read DOCX without Office; EPUB with a table of contents, one chapter at a time, with whole-book find.
- Video previews gain playback controls: play/pause, seeking, frame step, volume and speed. When a system decoder (such as HEVC or AV1) is missing, a card explains it and links to the Microsoft Store.
- Images: animated WebP and APNG play; ICO / CUR icons switch between their sizes; HEIC / AVIF show how to get the missing system extension.
- Settings > General adds "Quick Look · Supported formats", listing every previewable format by category and checking whether the HEIF / HEVC / AV1 / WebP system extensions are installed.

### Staging tray

- Add a text diff window: when comparing two text files in the tray, choose View diff or Compare these two files from the batch menu. It offers side-by-side and unified views, inline character highlights, changes-only folding, ignore whitespace/case, swap sides, F7/Shift+F7 navigation, a minimap and copying of selected lines, and shows encoding and line endings.
- Add a tray compare mode showing location, modified time, size and whether contents match; binary files are labelled.
- Flag staged items that were moved or deleted, with one-click removal.
- Batches can be toggled between copy and move: drops copy by default, Shift moves, and copy batches stay after dropping. The whole tray can be dragged out at once.

### Browsing and search

- Add list grouping by name, date, type or size, with a permanent Group button on the toolbar and per-folder settings; Downloads and Recent group by date by default.
- Group and Sort now use wheel pickers with a live preview.
- Add dual-pane folder comparison highlighting differing, missing and newer items.
- Redesign address-bar search with a wider box, unclipped filter labels and consistent tooltips.
- Improve advanced search interaction and keep its criteria and state.
- Middle-click opens a folder in a background tab, Ctrl+middle-click in the foreground; opening a folder that is already open switches to its tab.

### Interface

- Animate window minimize and maximize.
- Add contextual tips that surface shortcuts and hidden features; they can be turned off or reset in Settings.
- Add Auto / Sharp / Smooth text rendering modes.
- Fix text caret display issues, plus other stability and polish improvements.

Available as a Windows 10/11 x64 installer, a Windows 8.1 compatible installer and a portable ZIP. Preview components and visual effects may vary by system.
