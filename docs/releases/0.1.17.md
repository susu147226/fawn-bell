# 鹿铃 0.1.17

## 修复：卸载卡死

上一版的卸载脚本里有这么一行：

```
ExecWait '"$INSTDIR\Luling.Index.exe" --stop'
```

`Luling.Index.exe` **不认识 `--stop`**，于是它按正常方式启动并一直运行，而卸载器用 `ExecWait`
在等它退出——**双方永久卡住**，进度条停在那一行不动。

现在改为不会阻塞的做法：`taskkill` 结束残留进程、`sc stop`/`sc delete` 处理服务，都立即返回。

## 安装 / 卸载

- `LulingSetup-0.1.17.exe`
- `Luling-0.1.17-portable-win-x64.zip`

**注意**：请把安装包**复制到桌面等普通目录**再运行。

**如果上一版卸载卡住了**：在任务管理器里结束 `Luling.Index.exe`（以及正在运行的卸载程序），
然后手工删掉安装目录与 `%LOCALAPPDATA%\Luling` 即可，不必等它。
