# 鹿铃 0.2.5 · 拖得顺手一点

## 拖动默认回到「剪切」

上一版我修一个拖放细节时用力过猛：把「拖拽源希望的效果」固定写成了复制。而
Luling 自己的接收方会读这个值，读到复制就跳过了「同盘移动」的判断 —— 结果
**所有内部拖动都变成了复制**，压缩包、文件夹、文件都是。

现在：

| 操作 | 效果 |
| --- | --- |
| 同盘拖到文件夹 | **剪切**（移动） |
| `Ctrl` + 拖动 | 复制 |
| 跨盘拖动 | 复制（标准行为；跨盘的"移动"实为复制后删除，中断有风险） |
| `Shift` + 拖动 | 强制移动 |

## 第三方右键项可以调顺序了

设置 › 右键菜单 › 展开「软件」卡片，那里的第三方软件行现在可以**按住拖动**：

- 拖动时显示一条插入线，落点一目了然
- 松手即重排并保存，重启后保持
- 没拖过的行保持发现顺序，以后新装的软件仍会自动出现

## 顺手加了一个快捷键

`Alt+↓` 打开当前高亮的文件或文件夹 —— 不用松手去按回车。

## 一句实话

还试着给第三方右键项补上图标（从注册表里找程序或扩展 DLL 的图标）。**效果因
软件而异**：一部分能显示，靠扩展自己绘制图标的那些仍然没有 —— 这类图标不在
注册表里，取不到就是不显示，不会画一个错的。
