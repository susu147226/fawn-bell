# 鹿铃 0.1.9

## 安装：真正的根因找到了（恢复提权）

作者一句"**为什么 Pulse 的安装没问题，改动过后的就有问题了**"把方向纠正了过来——不是环境拦截，
是我自己改坏的。

回顾：上游安装器本来有「**未提权就自我提权重启**」的逻辑，我在做"用户级安装"时**把它删掉了**，
以为装到 `%LOCALAPPDATA%\Programs` 不需要管理员。但那个目录的 ACL 是：

```
SYSTEM:(OI)(CI)(F)
BUILTIN\Administrators:(OI)(CI)(F)
HLYS055\Administrator:(OI)(CI)(F)
```

**没有 Users 组**——因为 `Python`、`Xmind` 那些是**提权装进去的**，整棵树只授权给管理员。
所以过滤令牌下的安装器**建不了子目录**，报的正是"拒绝访问"；而 Pulse 会自动提权，所以从来没事。

这一版**恢复提权逻辑**，与上游一致。

## 新增：程序自身的安装 / 卸载

列表空白处右键多出两项，由**程序自己**完成，不经过安装器（便携版也能用）：

- **安装到系统…** —— 创建桌面与开始菜单快捷方式，并写入**当前用户**的卸载项
  （之后可在 Windows「设置 → 应用」里卸载）
- **从系统卸载…** —— 删除快捷方式与卸载项，并在退出后删除程序目录

## 其它（0.1.8 已包含）

- **归档素材重写**：所有路径先去掉 `\\?\` 前缀（`CreateDirectoryW`/`MoveFileW` 对扩展路径
  会静默失败），每一步写 `%LOCALAPPDATA%\Luling\refile.log`
- **批量重命名**：修掉规则框里残留的 `{`（`{n}{ext}` 是 8 个字符）、前缀后自动补 `_`、
  「更多选项」与输入框的间距
