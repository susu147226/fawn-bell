# 鹿铃 0.5.4

这一版修复了删除、复制卡住不动的问题，并让批量重命名在被占用时说清楚是谁占着。

## 修复

- 删除或复制时进度一直停在 0%，既不报错也不结束。原因是后台 Shell 宿主里某个右键扩展没有返回，把同一个进程里的文件操作一起堵住了。
- 现在等待超过约 15 秒仍然没有任何进度时，鹿铃会回收这个宿主，并把操作自动交给新宿主重试一次，不再需要手动去任务管理器结束进程。
- 批量重命名时如果有文件被其他程序占用，会列出占用它的程序，并可以直接结束该程序后重试；其余能改的文件照常改名。
