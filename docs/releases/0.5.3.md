# 鹿铃 0.5.3

这一版让右键菜单恢复常驻，不再被单个卡住的扩展拖慢。

## 修复

- 右键菜单不再因为某一个扩展没有及时返回就重启后台的 Shell 宿主。之前每次出现这种情况，下一次右键都要重新启动宿主并重新加载全部扩展，响应明显变慢。
- 后台宿主现在会连续工作更久，只有泄漏的处理线程累积到一定数量、或长时间没有操作时才会重建。
- 删除或复制时如果提示被占用，占用程序列表里会出现鹿铃自己的后台 Shell 宿主，可以直接结束它并重试，不需要再去任务管理器手动结束。
- 对迟迟不返回的右键扩展，鹿铃现在能正确把它标记为慢扩展；多次拖慢菜单后会自动跳过它，右键会越来越快。
