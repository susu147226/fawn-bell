### 更新并重启

- 点击一次“更新并重启”，自动下载并校验安装包；有文件操作或索引迁移时等待任务完成，无需重新下载或再点重试。
- 退出前保存窗口、标签页和分栏状态，静默安装完成后重新打开并恢复工作现场。即使平时设置为打开默认位置，本次更新仍恢复原标签，不改变启动偏好。
- 保留 Windows 必要的管理员确认。校验或保存失败会中止升级；静默更新不会强制结束正在操作文件的 Pulse。
- 新流程从本版客户端起生效；由旧版升级到本版时，入口仍由旧版客户端控制。免安装版继续通过新版 ZIP 更新。

### Markdown 与问题修复

- Markdown 预览增加原生数学公式，支持常用分式、根式、矩阵、局部宏和数学字体；不支持的表达式保留源码。
- 修复取消默认文件管理器后，旧版关联残留导致系统资源管理器无法打开的问题。（#81）
- 文件列表选中效果更易与悬停区分。（#78）
- 地址栏支持环境变量和 shell: 特殊文件夹。（#54）
- 修复右键“发送到”子菜单。（#77）
- 可在侧边栏隐藏 OneDrive，点击“此电脑”标题打开对应页面。（#80）
