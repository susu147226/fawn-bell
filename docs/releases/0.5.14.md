# 鹿铃 0.5.14

这一版修批量重命名。

## 批量重命名

- **预览不再误报冲突**。目标名属于「本批次里另一个即将改名的文件」时，不再标红。例如把 `bg_1..bg_8` 改成 `bg_0..bg_7`，之前每一行都提示「名称冲突」，现在显示 0 冲突。
- **执行按依赖顺序处理**。目标位置还被本批次里另一个未改名的文件占着时，先处理占用者，再回来改这一项。之前整体移位时只有最后一个文件能成功，其余全部被拒。
- 仍然保留「不覆盖」语义：和批次以外的文件重名、或两项互换名字这种循环，照常报冲突。
