### Browsing and lists

- Renaming or creating an item no longer re-sorts the list right away: a renamed item stays in its row and stays selected, and a new file or folder appears at the end of the list. Press F5, change the sort or reopen the folder to sort again; the selection follows the item to its new row.
- Each folder remembers its own sort order; the new "Apply view and sort to all folders…" makes every folder match the current one (grouping is not affected).
- The Details view adds Created and Accessed columns. Right-click the column header to choose which columns are shown or reset them; both new columns can be sorted and grouped by.
- Drives in This PC show their kind (local disk, removable drive, network drive, CD drive, RAM disk) instead of a 1601-01-01 date.

### Startup and tabs

- Settings > General > Startup & shutdown adds:
  - a default location (a folder or This PC);
  - When Pulse starts: the last tabs, or only the default location;
  - New tabs open: the current folder, or the default location.
- When "When Pulse starts" is set to the default location, restoring the window from the tray also returns to it.
- Starting Pulse with a file path (for example "Open file location" with Pulse as the default file manager) now selects that file instead of only switching to its folder.

### Search and address bar

- In quick search (Alt+Space), press Shift+Enter or click "Search in Pulse" in the footer to carry the same query, mode and scope to the main window, with all results in a new tab; Back returns to the folder.
- Type cmd, powershell, pwsh or wt in the address bar to open a terminal in the current folder.

### Context menu

- Windows 11 style context-menu entries are shown, for example those from WinRAR 7, NanaZip, VS Code, Bandizip and Windows Terminal.
- Settings > Context menu adds "Pulse commands", where Pulse's own commands (such as tags and select all / invert) and file row buttons can be hidden.
- Context menus, dropdowns and the command palette follow the list row height: Compact / Standard / Comfortable give 30 / 36 / 40 pixel rows; the default look is unchanged.
- Fix long menu labels being cut off without an ellipsis; hover a truncated label to see the full text.

### Interface

- The sidebar scrollbar stays hidden until you scroll, and widens when the pointer is on it so it is easy to drag.
- Shortcut help lists every shortcut, grouped into navigate, files, search, select, and tabs and panes; fix it closing at once when opened from "All shortcuts" in the status bar.
- Fix a second, ghost set of caption buttons appearing at the top right of the window. Right-clicking the title bar no longer opens the system menu.

### Fixes

- Opened files and batch scripts start in their own folder.
- Quick access badges are no longer lost after a restart.
- Fix text fields in the advanced search and batch rename dialogs sometimes showing no text and not taking focus again.
