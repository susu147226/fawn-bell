# 鹿铃 0.1.1

本版本修复了一批实际使用中遇到的问题，并加上两个作者惯用的批量操作。

## 新增

- **新建菜单支持全部类型**：不再只有文件夹与文本文档，菜单按系统注册表
  （`ShellNew`）列出所有可新建的类型，含 Office 文档这类模板类型。
- **按序号重命名（从 0 开始 / 从 1 开始）**：右键菜单新增两项。按扩展名分组、
  组内按自然顺序排列，每组各自从所选起点编号；执行前有预览，可先改前缀。
- **追加文件名后缀**：右键菜单新增一项，在文件名与扩展名之间插入设定的文本
  （默认 `_1×2`）。
- **地址栏历史下拉**：地址栏按 ↓ 列出访问过的文件夹，选中即跳转。

以上右键菜单项都可以在「设置 → 右键菜单」里显示、隐藏与排序。

## 修复

- **第三方应用打开无响应**：从右键菜单用 VS Code、WPS 这类应用打开文件时没有
  反应；现在与资源管理器一致。
- **右键菜单漏项**：补上挂在 `*\shell` 下的第三方动词（例如 Bandizip 的压缩 /
  解压），并修掉动态子菜单被超时丢弃的问题。
- **地址栏粘贴**：支持粘贴一段或多段路径；多段路径每行各开一个标签页，第一行
  留在当前页。

## 安装

- 安装版：`LulingSetup-0.1.1.exe`，可勾选注册 LulingIndex 索引服务（全盘即时搜索）
- 免安装版：`Luling-0.1.1-portable-win-x64.zip`，解压即用，索引服务需用安装版部署
