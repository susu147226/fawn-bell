# 鹿铃 0.2.9 · 支持手机

这一版可以直接浏览和整理通过 USB 连接的手机（MTP）与相机。

## 手机设备

- 「此电脑」和左侧栏会显示已连接的手机设备。
- 双击进入，浏览内部存储和文件夹。
- 支持打开文件、复制、剪切、重命名、删除。
- 手机 ↔ 电脑：用 `Ctrl+C` / `Ctrl+V` 双向复制或剪切。
- 手机内部复制会自动采用「先下载到临时目录、再上传」的方式，因为 MTP
  不支持设备内直接复制。大文件会有两段传输耗时。
- 手机没有回收站，删除时会弹出永久删除确认。

## 快捷键调整

- `Ctrl+D`：删除（与 `Delete` 相同；`Shift+Delete` 仍是永久删除）。
- 原先 `Ctrl+D` 的「标记目标窗格」改为 `Shift+D`。
