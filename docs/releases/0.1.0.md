# 鹿铃 0.1.0

首个版本。

## 关于这个版本

鹿铃是 Windows 上的文件管理器。本版本以 [Pulse](https://github.com/jimmgreen/pulse) v1.0.53 为基线
（Apache License 2.0），在此之上完成改名、品牌化与许可分层；作为第一个版本，它不含「相对上一版」的
功能变更，重点是确认基线可用、构建与测试链路就位。

## 本版本提供

- 多标签与多窗格、八种视图、排序与分组、五档分栏
- 全盘索引与拼音搜索、内容搜索
- 空格快速预览：文本与代码、图片、Markdown、表格、压缩包、文档等
- 暂存盘、拖放与剪贴板、文件与文件夹操作、批量重命名、文本与文件夹比对
- 简体中文 / 繁體中文 / English 三语界面，浅色与深色主题
- 安装版与免安装版

## 安装

- 安装版：`LulingSetup-0.1.0.exe`，可勾选注册 LulingIndex 索引服务（全盘即时搜索）
- 免安装版：`Luling-0.1.0-portable-win-x64.zip`，解压即用，索引服务需用安装版部署
