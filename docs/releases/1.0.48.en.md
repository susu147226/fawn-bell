National Day edition: Traditional Chinese interface.

### Traditional Chinese

- Added a Traditional Chinese interface using Taiwan terminology. It is selected automatically when the Windows display language is Traditional Chinese (Taiwan, Hong Kong or Macao), or can be chosen in Settings → Display language.
- The Traditional Chinese interface uses Microsoft JhengHei UI; the installer is also available in Traditional Chinese.
- Context-menu grouping and file-operation error handling recognize Traditional Chinese Windows, and the kind: search filter accepts Traditional Chinese keywords.

### Fixes

- Fixed a Chinese unit appearing in a file-size label in the English interface.
- The command menu's search placeholder now follows the interface language.
- Preview format descriptions refresh immediately after switching between Simplified and Traditional Chinese.

Available as Windows 10/11 x64 and Windows 8.1 installers, plus a portable Windows 10/11 x64 ZIP.
