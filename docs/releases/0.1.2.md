# 鹿铃 0.1.2

本版修复 0.1.1 实机使用中发现的问题。版本号升到此号是为了能一眼分辨手里的构建。

## 修复

- **新建菜单**：支持 `Command` 型 ShellNew 项。WPS 把「WPS PDF 文档」「WPS AI 生成 PPT」注册成
  `Command` 形态，此前被本程序过滤掉，现在会照常列出并可点击。
- **归档素材**：文件名不含下划线时按**主名**建文件夹（此前用含扩展名的全名，与自身同名而
  静默跳过）；没有任何文件被归档时会给出提示，不再毫无反应。
- **地址栏历史**：下拉宽度改为地址栏的 1.8 倍（最少 560 px），能辨认完整路径；位置下移，
  不再遮挡正在编辑的地址。
- **安装程序**：改为在启动时申请管理员权限（此前依赖运行时自我提权，可能在创建暂存目录
  之前就失败，且报出「找不到路径」这种与实际原因不符的错误）；目录创建失败时报告真实原因。
- **打开失败不再静默**：`ShellExecuteEx` 失败时弹框说明系统给出的原因。

## 安装

- 安装版：`LulingSetup-0.1.2.exe`
- 免安装版：`Luling-0.1.2-portable-win-x64.zip`
