# 鹿铃 0.4.3 · 复选框与文件树箭头不再重叠

这一版修复同时开启「项目复选框」和「文件树」时的行内布局冲突。

## 修复

- 文件夹行的展开箭头此前与复选框重叠：两者都按文件夹图标的位置计算，树缩进后箭头正好落进复选框里。
- 复选框现在固定在行左侧的预留列内，不随树缩进移动；展开箭头独占缩进区，二者不再相交。
- 复选框列加宽到 26 dip，复选框与箭头之间留出约 6 px 的间距，不再显得局促。
- 表头「全选」框同步对齐到与行复选框相同的位置，命中区域与绘制一致。

## 包含 0.4.2 的修复

- 预览进程改为共享打开；删除、移到回收站、永久删除、重命名和移动前自动关闭预览，不再被 FFmpeg/WIC 占用。
- 移动设备可新建文件夹与文件，修复「无效的字符串」，工具栏「新建」外观与实际能力一致。
- 设备上的重命名、删除、双向复制与拖动可用。
