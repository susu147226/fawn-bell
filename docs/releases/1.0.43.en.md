### Staging tray

- Add a text diff window: when comparing two text files in the tray, choose View diff or Compare these two files from the batch menu. It offers side-by-side and unified views, inline character highlights, changes-only folding, ignore whitespace/case, swap sides, F7/Shift+F7 navigation, a minimap and copying of selected lines, and shows encoding and line endings.
- Add a tray compare mode showing location, modified time, size and whether contents match; binary files are labelled.
- Flag staged items that were moved or deleted, with one-click removal.
- Batches can be toggled between copy and move: drops copy by default, Shift moves, and copy batches stay after dropping. The whole tray can be dragged out at once.

### Browsing and search

- Add list grouping by name, date, type or size, with a permanent Group button on the toolbar and per-folder settings; Downloads and Recent group by date by default.
- Add dual-pane folder comparison highlighting differing, missing and newer items.
- Redesign address-bar search with a wider box, unclipped filter labels and consistent tooltips.
- Improve Advanced Search interaction and keep its criteria and state.
- Middle-click opens folders in a background tab; Ctrl+middle-click opens them in the foreground.

### Interface

- Add contextual hints for shortcuts and hidden features; they can be turned off or reset in Settings.
- Add Auto / Sharp / Smooth text rendering modes.
- Fix text-box caret display, plus other stability and polish improvements.

A Windows 10/11 x64 installer is available. Preview components and visual effects vary by operating system.
