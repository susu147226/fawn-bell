# 鹿铃 0.1.23

## 修复：图像与 RAW 相机增强包装不上

「现代图像格式」与「RAW 相机照片」两个包，无论从设置里下载、还是用含全部预览包的
完整版安装，装完都仍然显示**未安装**。

原因是改名时改过头了：程序判断「包是否已安装」靠的是包内主程序的名字，而这两个包的
主程序是**上游预编译的二进制**，名字叫 `pulse-imgpack.exe` 与 `pulse-rawpack.exe`。
改名时把它们也改成了 `luling-`，于是程序在一个**永远不存在**的文件上做判断——包其实
已经解压好了，只是被当成没装。视频（ffmpeg）与压缩包（7z）两个包的名字本来就不是
`pulse-` 前缀，所以一直正常。

现在改回真实包名。目录清单里的哈希覆盖的正是这些名字，因此校验逻辑不受影响。

> 已经装过这两个包的机器：更新到本版后再次点「下载并安装」即可，文件本来就在，
> 只是此前没被认出来。

## 修复：应用内更新「显示成功」，但版本号没变

在应用里更新，提示装完了，**关于页仍显示旧版本号**——因为实际上一个文件都没换。

应用是**先拉起安装器、再关闭自己**，两者之间有窗口期；而我之前特意让静默安装**不结束
`luling.exe`**（怕窗口回不来）。结果安装器开始复制文件时应用还开着，`luling.exe` 被占用，
写入失败；而 `/S` 会**抑制错误提示并静默中止**，退出码却仍是 0——应用于是报告成功，
重新起来的还是旧版本。

现在静默运行时也照常结束应用（反正结尾会用 `explorer.exe` 把它拉回来），文件锁随之消失。

## 安装 / 卸载：两个安装包

| 产物 | 大小 | 说明 |
| --- | --- | --- |
| `LulingSetup-0.1.23.exe` | 约 7.7 MB | 标准版，不带预览增强包，需要时在设置里下载 |
| `LulingSetup-0.1.23-full.exe` | 约 27 MB | **含全部预览增强包**，装完即用，适合下载源不可达的机器 |
| `Luling-0.1.23-portable-win-x64.zip` | 约 31 MB | 免安装版，**默认含全部预览增强包** |

应用内自动更新指向**标准版**；离线需求请手动下载 full 版或便携版。

**注意**：请把安装包**复制到桌面等普通目录**再运行。
