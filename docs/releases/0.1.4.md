# 鹿铃 0.1.4

## 安装程序：换掉目录创建的实现

上一版把安装改成了用户级（`%LOCALAPPDATA%\Programs\Luling`），但仍报
`Cannot create ... staging: error 3 系统找不到指定的路径`——连用户目录都建不出来，
说明问题不在权限，而在**创建目录这一步本身**。

这一版把目录创建从 `SHCreateDirectoryExW` 换成标准库的
`std::filesystem::create_directories`，并把失败原因**如实**带出来：

- 如果是**拒绝访问**，就报"拒绝访问"
- 如果是**路径不存在**，就报"路径不存在"

无论哪种，安装器都会把 `%TEMP%\Luling-Setup-<时间戳>.log` 写下来（界面上「打开安装日志」
按钮指向它）。**如果这一版仍然装不上，请把那个日志文件发我**——里面会逐行记录走到哪一步，
一次就能定位。

## 安装

- 安装版：`LulingSetup-0.1.4.exe`
- 免安装版：`Luling-0.1.4-portable-win-x64.zip`（若安装仍有问题，用这个，功能完全一样）
