# 鹿铃 0.3.2 · 右键菜单响应与第三方扩展

这一版修复 0.3.1 中右键菜单变慢、第三方菜单项消失的问题。

## 右键菜单

- 打开文件或文件夹的右键菜单不再停顿约两秒。
- 第三方软件（7-Zip、压缩工具、Git 等）的菜单项恢复显示。
- 选中文件后工具栏操作条上的 `⋯` 同样立即响应。
- 始终不响应的 Shell 扩展会在约 0.9 秒后被跳过，不再拖住整张菜单。
