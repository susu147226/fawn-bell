Bug-fix release: issues reported on GitHub, plus fixes contributed by the community.

### File operations

- Copying many small files is faster: files under 64 MB whose destination is free are written straight to their final name instead of through a temporary file. Large files and replacements still go through a temporary file, so a failure never damages the original. (#60)
- Moving several items within one drive now renames them instead of copying and deleting each file; undo still works. (#60)
- Files dragged out of 7-Zip, WinRAR or Bandizip are staged before name conflicts are resolved, fixing "path not found" after choosing Replace or Keep both. (#55)
- Fixed double-click open failing with "cannot find the file" for some files such as .json or .md. (#55)
- Drops from browser download lists, archive tools and similar sources are always copied when the source asks for a copy, so the original is never deleted. (thanks @sdcxb, #61)
- When a replace fails and cannot be rolled back, the error now names the kept backup file. (thanks @sdcxb, #63)
- After closing the program that locked a file, plain Retry skips the items that were already handled.
- Sorting by size orders folders by their actual totals. (#58)

### This PC and navigation

- This PC remembers its view mode, sorts drives by letter and shows a usage bar and free space for each drive in tile view.
- Double-clicking empty space or pressing Up at a drive root goes to This PC; splitting the view from This PC opens This PC in the new pane. (#68)

### Context menu and shell integration

- When a third-party context-menu extension hangs, the menu shows the other items after 5 seconds and the menu host is restarted once idle instead of piling up; an extension that hangs three times is turned off. (#65)
- Partial context-menu results are no longer cached, fixing WinRAR and other submenus that sometimes went missing. (thanks @sdcxb, #59, #62)
- The context-menu host only accepts requests from the Pulse that started it. (thanks @sdcxb, #64)
- Uninstalling restores the previous handler for This PC.
- With "Show accent color on title bars" on, the title bar is no longer split into two colors. (#20)

### Search and index

- The full-disk index service only returns results from folders the current user can list, so other users' profile contents no longer appear in search. (#66)

### Install and update

- Updates now install in place, so Pulse pinned to the taskbar or Start keeps its pin. (#72)
- Settings → About & diagnostics → Software update has a "Check for updates automatically" switch (on by default).

### Interface

- The Sort, Group and Filter toolbar buttons fit their labels, and their drop-down chevrons animate.
- In high contrast, every text box uses the system colors.
- The folder picker only lets you choose folders that are confirmed to exist while it loads.
- Remaining Chinese text in the English interface is translated, and operation errors show the real file names.

Available as Windows 10/11 x64 and Windows 8.1 installers, plus a portable Windows 10/11 x64 ZIP.
