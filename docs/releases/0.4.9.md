# 鹿铃 0.4.9 · 时间卡片可拖动窗口

这一版给标题栏时间卡片补了一个窗口拖动手势。

## 标题栏时间卡片

- 在卡片上按住 **Alt + 鼠标左键** 拖动，可以移动窗口，和标签页上的同款手势走同一条路径。
- 普通左键单击仍然是切换三页；右键仍然是打开日程面板，三者互不影响。
