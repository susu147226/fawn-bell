# 鹿铃 0.5.8

这一版带来了真正的插件系统：扩展不再只能跑命令行，而是可以在独立进程里提供命令、预览、列和侧栏面板。

## 新增：插件系统

- 新增插件宿主进程 `Luling.Plugin.exe`。插件以 DLL 形式运行在独立的宿主进程里，主程序通过命名管道调用它；插件崩溃或卡死不会拖垮鹿铃。
- 插件清单升级到 schema 2，通过 `capabilities` 声明能力，目前的扩展点包括：
  - **命令**：右键菜单「扩展」子菜单和 Ctrl+K 命令面板。
  - **预览器**：按扩展名为详情面板和空格快速预览绘制位图。
  - **列提供者**：在文件列表中最多添加两列，随滚动按需取值，并支持按该列排序。
  - **侧栏面板**：在侧栏添加一个声明式面板，点击行回调插件。
- 授权与插件的**版本和能力集**绑定：插件升级或新增能力后会重新征求同意，旧授权自动失效。
- 商店安装现在会校验安装包的 SHA-256，缺失或对不上都会拒绝；「已安装」页可以停用、启用或卸载扩展，旧版（schema 1）扩展会标上「旧版扩展」。

## 修复

- 「此电脑」的网盘程序入口在类型列里直接显示了 `{name}` 模板文本，现在正确替换成程序名。
- 文件列表的列标题不再使用半粗字重，与其余界面一致。
- 详情面板的预览在解码结果到达时会被缓存淘汰，导致一直停在「正在加载预览」。
