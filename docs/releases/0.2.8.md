# 鹿铃 0.2.8 · 把「重启」和「退出」说清楚

这一版解决一个容易误会的问题：关掉窗口不等于完全退出。现在三处都明确了：

## 新增「重启鹿铃」

- **托盘右键菜单**：打开 / **重启鹿铃** / 退出。
- **设置 → 关于**：多了一个「重启鹿铃」按钮。

点击后，鹿铃会保存当前会话、启动新进程并退出旧进程，窗口重新出现。
新进程启动约 15 秒后自动检查更新，不再需要你去任务管理器里确认有没有退干净。

## 关闭到托盘时给出提示

如果开启了「关闭后继续运行」或全局搜索，第一次关闭窗口时，托盘会弹出一次提示：

> 鹿铃仍在后台运行
> 右键托盘图标可打开菜单；选择「退出」可完全退出。

这个提示只出现一次，之后不再打扰。

## 索引进程随主程序一起退出

之前 `Luling.Index.exe` 在主程序退出后还要等 15 秒空闲才走，看起来像“没退干净”。
现在主程序退出时会通知自己启动的索引助手立即退出；如果安装的是全盘索引**服务**，
服务仍会照常常驻，这是预期行为。

## 修复：第三方右键项排序后开关错位

在「设置 → 右键菜单」里拖动第三方软件项后，开关可能改到别的软件上，菜单里点
某一项也可能执行另一项。原因是设置页按新顺序显示，点击处理却仍按原始顺序取
条目。现在显示和操作使用同一份顺序。
