### System integration and startup

- Set Pulse as the default file manager for folders, Win+E and This PC. Opening a file's location can select the file in Pulse.
- Added an experimental option to take over Explorer windows opened directly by other applications.
- Added options to start in the tray at sign-in and close the window when the last tab closes.
- Double-clicking empty space in a file list can now navigate to the parent folder.

### Dialogs and file operations

- Unified confirmation dialogs and folder/picture pickers, with improved keyboard focus, high-contrast rendering and DPI-aware layout.
- Locked-file prompts identify the processes holding an item and offer an end-process-and-retry action.
- Improved truncation of long paths and folder names. Missing-folder messages identify the requested path.
- Fixed invalid paths during folder-picker navigation and keyboard input being routed to a disabled owner window instead of its dialog.

### Interface and performance

- Grouped settings and theme switching in a title-bar pill.
- Show filename tooltips only when the name is truncated, including corrected measurement in icon view.
- Use the localized Downloads name in the sidebar.
- Moved preview-codec probing and machine verb-cache reads off the UI thread, and coalesced Shell registry notifications to reduce blocking and redundant refreshes.

Available as Windows 10/11 x64 and Windows 8.1 installers, plus a portable Windows 10/11 x64 ZIP.
