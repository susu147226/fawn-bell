# 鹿铃 0.1.15

## 批量重命名对话框

- **「查找」「替换」的标签在简单模式下不再绘制**——它们之前无论如何都会画，正好压在「新名字」上，
  这是之前"重叠"的真正原因（字段本身早已按需隐藏，漏掉的是两个标签）。
- **「更多选项」展开后仍可点击**，用来收回高级字段；按钮文字相应变成「收起选项」。以前它只在
  简单模式下命中，展开后就没有返回的入口。

## 安装

- `LulingSetup-0.1.15.exe`
- `Luling-0.1.15-portable-win-x64.zip`

**注意**：请把安装包**复制到桌面等普通目录**再运行（从本会话工作目录启动会继承沙箱上下文）。
