# 鹿铃 0.1.21

## 修复：装了全盘索引服务时，安装会弹出「无法打开要写入的文件」

如果你开着全盘索引服务，运行 0.1.20 的安装程序会中途弹出：

```
无法打开要写入的文件:
    "…\Luling.Index.exe"
```

原因在清理顺序上：安装程序**先结束进程、再停服务**。而被结束的正是索引服务进程——
Windows 的服务管理器立刻又把它拉了起来，于是等真正开始写文件时，`Luling.Index.exe`
又被占用，写入被拒。

上一版引入「安装前先清空旧版本」时踩到了这一点。现在顺序反过来：**先把服务停掉并删除，
再结束进程**，并在杀完之后留一点时间让镜像卸载，然后再开始复制文件。服务若原本存在，
装完仍会自动注册回来。

> 如果你刚才卡在那个对话框上：点**中止**，然后用这一版重新安装即可——它会先清理干净。
> 也可以手动执行 `sc stop LulingIndex` 与 `sc delete LulingIndex` 后让旧安装程序重试。

## 安装 / 卸载：两个安装包

| 产物 | 大小 | 说明 |
| --- | --- | --- |
| `LulingSetup-0.1.21.exe` | 约 7.7 MB | 标准版，不带预览增强包，需要时在设置里下载 |
| `LulingSetup-0.1.21-full.exe` | 约 27 MB | **含全部预览增强包**，装完即用，适合下载源不可达的机器 |

应用内自动更新指向**标准版**；离线需求请手动下载 full 版或便携版。

**注意**：请把安装包**复制到桌面等普通目录**再运行。
