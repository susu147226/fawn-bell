# 鹿铃 0.4.2 · 预览不再锁文件与移动设备补全

这一版修复预览进程占用文件导致操作失败的问题，并补齐移动设备（MTP）上的新建、重命名、删除与拖放。

## 预览与文件操作

- 正在预览 GIF 时删除或重命名文件，不再提示「文件被占用」：GIF 帧解码改用允许删除共享的读取句柄。
- 文档预览与索引进程打开文件时改为允许读写、删除共享，不再阻止对同一文件的重命名、写入或删除；重新打开失败时只跳过该文档。
- 删除、移到回收站、永久删除、重命名和移动前会自动关闭快速预览与悬停预览。视频播放依赖的 FFmpeg 不提供删除共享，此前会把这些操作卡成共享冲突。
- 拖放复制不受影响：源文件仍可被举出，目标端写入完成后正常释放。

## 移动设备（MTP）

- 设备文件夹中的「新建文件夹」和「新建文件」现在可用，名称冲突时会自动追加序号。
- 修复在设备上新建时报「无效的字符串」：Shell 宿主直接按 ID 列表构造 Shell 项，不再尝试按解析名重新打开。
- 修复设备工具栏「新建」按钮呈禁用外观、实际却可以点击的问题；现在外观与实际能力一致。
- 设备上的重命名、删除、本机与设备之间的双向复制和拖动均已验证。
