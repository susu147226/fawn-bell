功能与问题修复版：继续处理 GitHub 上反馈的问题。

### 右键菜单

- 菜单比屏幕还高时，不再超出屏幕底部：菜单会限制在屏幕内，顶部和底部出现滚动箭头。鼠标停在箭头上持续滚动，点击翻页，也可以用滚轮或键盘 ↑/↓。（#67）
- 刚打开右键菜单时，“新建”、压缩软件等系统菜单项稍后到达也会直接补进当前菜单，不用再右键第二次。（#73）

### 搜索

- 在没有加入网络索引的网络文件夹（UNC 路径）里搜索文件名，会实时遍历该文件夹并陆续显示结果，不再一无所获；结果上方提供“加入网络索引”按钮，加入后搜索更快。（#74）

### 文件列表与分组

- 分组菜单和分组轮盘新增“将分组应用到所有文件夹…”：确认后，所有文件夹（包括从未打开过的）都按当前方式分组，之前单独保存的分组会被清除；之后仍可为单个文件夹另行设置。最近使用、搜索结果、标签和回收站保留各自的分组。（#75）
- 设置中新增“删除前确认”（默认关闭）：开启后，按 Delete 移到回收站前会先询问；永久删除始终会确认。（#71）

### 托盘

- 设置 → 启动与关闭 新增“托盘图标”：始终显示 / 仅后台运行时 / 不显示。选“不显示”时，关闭窗口后 Pulse 仍可在后台运行，再次打开 Pulse 即可找回窗口；命令面板（Ctrl+Shift+K）中新增“退出 Pulse”。（#57）

### 安装与更新

- 从旧版本升级时，安装程序会先让正在运行（包括缩到托盘）的 Pulse 保存标签页和布局后退出，再静默覆盖原安装位置，不再提示“Pulse 正忙”而中断。正在复制或移动文件时会等待其完成，不会打断。

提供 Windows 10/11 x64 安装版、Windows 8.1 兼容版和免安装版。
