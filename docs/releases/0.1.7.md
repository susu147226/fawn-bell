# 鹿铃 0.1.7

## 安装：去掉暂存目录

上一版把真实错误暴露出来了：**`error 5 拒绝访问`**——连 `%LOCALAPPDATA%\Programs\Luling`
都建不出来（而那是用户目录，`Python`、`Xmind` 都装在那里）。这说明拦截针对的是**安装器进程**，
而**它多建的那一层暂存目录**（`{app}\.luling-setup\staging`）正是第一个被拒的写操作。

这一版**取消暂存目录**：安装器直接把文件写进安装目录，不再先解压到中间目录再搬过去。
少一次目录创建，就少一个能被拒的入口。

## 归档素材：加了追踪（仍在定位）

这一版在**每一个菜单命令**的入口都写一行追踪：

```
%LOCALAPPDATA%\Luling\dispatch.log     ← 收到了哪个命令
%LOCALAPPDATA%\Luling\refile.log       ← 归档素材收到的文件列表
```

**请执行一次「归档素材」，然后把这两个文件发我。** 如果 `dispatch.log` 里没有对应的一行，
说明点击根本没到命令分派；如果有、但 `refile.log` 也没写，说明分派到了但没进到功能里。
有了这个，一次就能定位。
