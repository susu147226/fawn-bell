# 鹿铃 0.1.14

## 卸载现在会清干净

以前卸载只删程序目录，数据目录和部分注册表会留下（`%LOCALAPPDATA%\Luling` 里有 400 多 MB 的
索引文件，而且"已卸载"的鹿铃仍会出现在搜索里）。

现在两处卸载都完整清理：

- **安装程序**（NSIS 的 Uninstall 段）
- **程序内的「从系统卸载…」**（便携版用）

覆盖范围：程序目录、`%LOCALAPPDATA%\Luling` 与 `%LOCALAPPDATA%\鹿铃`、`%APPDATA%` 与
`%ProgramData%` 下的同名目录、桌面与开始菜单快捷方式、`HKCU`/`HKLM` 两处的卸载项与
`Software\Luling`、`LulingIndex` 服务、Shell 集成项。

数据目录里的索引文件可能被服务占着，删除会**重试三次**。

## 安装

- `LulingSetup-0.1.14.exe`
- `Luling-0.1.14-portable-win-x64.zip`

**注意**：请把安装包**复制到桌面等普通目录**再运行——从本会话工作目录启动会继承沙箱上下文。
另外，安装前请先卸载旧版（本版之前的卸载不干净，建议手工删掉 `C:\Program Files\Luling`、
`D:\鹿铃` 与 `%LOCALAPPDATA%\Luling`）。
