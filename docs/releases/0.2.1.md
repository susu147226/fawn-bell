# 鹿铃 0.2.1 · 补三个洞

0.2.0 刚放出去就收到几个问题，都修好了。这次没有新功能，只有修。

## 转换引擎点了没反应、装不上

在设置里点「下载并安装」，进度条不出现、也不报错，看着就像没点上；再点一次
反而把下载取消了 —— 因为按钮上明明写着「安装」，实际做的却是取消。

原因是这张卡片的状态从没接进界面：进度、结果都没人读。现在好了，下载中会显示
百分比和进度条，徽章变「正在安装」，按钮老老实实写成「取消」，成功、失败、取消
都会给一句话说明，不再一声不吭。

顺带修好：打开一个放不了的视频时程序会自动去下增强包，那次自动下载会把你正在
手动装的那次给掐掉。

## 视频放大到 400% 以后，画面定住不动

放大到大约四倍时画面会突然卡住。缩放要求的尺寸撞上了解码上限，程序却拿它和
**没截断**的尺寸去比，结论永远是「对不上」，于是每 80 毫秒重启一次解码器 ——
看起来就像暂停了。现在两边用同一个上限，一直到 800% 都照常播放。

## 缩小时只有画面变小，外框不动

放大是连框一起放大的，缩小却只有画面缩、框杵在原地。现在两个方向一致了。
