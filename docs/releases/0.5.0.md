# 鹿铃 0.5.0 · 地址栏补全与面包屑子文件夹

这一版补齐了地址栏的输入体验，并修掉了图片 / RAW 增强包一直没生效的问题。

## 地址栏

- **路径补全**：在地址栏输入时，下方会列出匹配的子文件夹和文件；第一行始终是「转到 你输入的内容」，直接回车就按输入的路径导航，用 ↑↓ 选中某一行再回车则采纳那一项。
- **从当前目录补全相对路径**：在某个目录里直接输入 `co` 这样的片段，会列出当前目录下匹配的项。
- **直接打开文件**：输入一个文件的完整路径回车，会跳到它所在的文件夹并选中它；以前会把文件路径当目录载入然后报错。
- 访问历史和补全共用同一个下拉：刚打开地址栏显示最近去过的文件夹，一开始输入就切换成补全。

## 面包屑

- 面包屑每一段右侧的分隔箭头现在可以点开，列出该目录下的一层子文件夹，选一个直接进去；点段的文字仍然是原来的跳转。

## 文件列表

- **筛选框支持拼音**：输入 `cs` 能找到「测试文档」，输入全拼同样有效；带 `*`、`?` 的输入仍按原来的通配语义处理。

## 修复

- **图片增强包与 RAW 增强包现在会真正生效**。预览宿主以前按 `luling-imgpack.exe` / `luling-rawpack.exe` 查找，而实际安装的是 `pulse-imgpack.exe` / `pulse-rawpack.exe`，找不到就放弃；HEIC / HEIF / AVIF / JXL 之类的缩略图和 RAW 预览因此一直没有走增强包路径。
- 标题栏时间卡片的节气行按当前日期重新计算，修掉跨天后出现「霜降15天—今天—1天立冬」这类拼错。
- 日程面板点卡片外的任意位置也能关闭。
- 第三方程序里「在文件管理器中打开」时，鹿铃窗口会回到前台，不再看起来像没反应。
