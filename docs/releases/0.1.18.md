# 鹿铃 0.1.18

## 重要修复：卸载不再破坏文件管理器

**上一版的卸载会把你带进一个很糟的状态**：接管功能写的注册表项指向安装目录里的 `luling.exe`，
而卸载从不去还原它们，还顺手把存放还原快照的 `Software\Luling` 一起删了。结果是卸载后
**双击文件夹打不开**，而且无法自动恢复。

现在卸载会**先**调用接管还原、确认恢复后才删注册表。便携版的「从系统卸载…」同样补上了这一步。

> 如果你已经在旧版上遇到过这个问题：进入「设置 → 通用」把接管关掉（或重新安装一次再正常卸载）即可恢复。

## 升级不再出现新旧混杂

安装包在写入文件前会先结束仍在运行的旧版进程。此前旧版在运行时安装，文件写入会失败，
留下新旧混杂的安装目录。

## 第三方右键项不再消失

「慢扩展自动禁用」会把查询较慢的 Shell 扩展**写进配置永久跳过**——装了 Bandizip、
7-Zip 等却看不到它们的「解压到…」，就是这个原因（你的配置里可能已经攒了几十个）。

现在慢扩展只会改成异步查询，**不会被跳过，也不会写进配置**。超时只影响当次。

## 右键菜单不再每次卡 5 秒

一个从不返回的扩展会让每次右键都白等满 5 秒（打开菜单是一瞬间的事，但点第三方项要等）。
等待上限收到 1.5 秒。实测从 5187 ms 降到 1504 ms。

## 地址栏回车失效

地址栏点开时弹出的历史下拉会**把回车吞掉**，所以粘贴路径后回车不跳转（粘贴本身没问题，
它只是让你看见了这个问题）。现在回车交还给地址栏。

## 网络位置无法删除文件

网络共享没有回收站，而删除链在遇到这种情况时**直接拒绝**、也没有降级。现在改为按资源管理器的
做法**永久删除**，并照常弹出确认。

## 全局搜索支持空格快速预览

Alt+Space 搜索窗口里选中一条结果后按空格即可预览，再按一次关闭。此前空格会被输入框吃掉。

## 更新检查失败时给出原因和出口

失败不再只有一句「检查失败」，而是区分网络 / 服务器 / 校验 / 地址不安全；同时提供
**「手动下载」**按钮直达发布页。

## 其它

- **显示器拔掉后窗口不再失踪**：显示配置变化时把越界窗口移回可见区域；命令面板新增「重置窗口位置」
- **切换列视图不再强制打开详情面板**
- **空白处右键有了「新建」子菜单**，与工具栏新建按钮内容一致
- **系统原生预览失焦后不再变空白**
- **切换列视图 / 刷新缩略图缓存**：命令面板新增「刷新缩略图缓存」
- **FFmpeg 预览包改为首次用到时自动安装**（仍可在设置里管理）
- 未安装索引服务时不再拉起索引进程，界面明示

## 安装 / 卸载

- `LulingSetup-0.1.18.exe`
- `Luling-0.1.18-portable-win-x64.zip`

**注意**：请把安装包**复制到桌面等普通目录**再运行。
