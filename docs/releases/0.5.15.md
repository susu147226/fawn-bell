# 鹿铃 0.5.15

两处改进。

## 设置不再占用标签

- 打开设置时，标签栏不再出现「设置」标签，也没有任何标签处于高亮状态。
- 点任意其他标签就离开设置，直接回到那个文件夹。
- Esc 或 Ctrl+W 关闭设置，回到打开设置前所在的标签。
- 设置的页面、滚动位置和展开状态都会记住，下次打开还在原处。

## 标题栏节气

- 节气当天，时间卡片直接显示节气名和一句简短描述（例如「小雪 / 开始降雪，天寒地冻」），不再显示「上一节气N天—今天—下一节气」。
- 非节气日保持原来的显示方式。
