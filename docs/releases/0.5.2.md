# 鹿铃 0.5.2

这一版修复了文件删不掉、也复制不了的问题。

## 修复

- 删除或复制文件时提示「可能需要管理员权限，或此项正被其他程序使用」，甚至操作一直停住。
- 原因是后台的 Shell 宿主进程被某个不返回的右键菜单扩展拖住了：扩展开着的文件既删不掉也复制不了，即使退出其他程序、退出鹿铃主窗口也不恢复。
- 现在宿主在没有其他任务时会自行退出，下一次右键或文件操作由鹿铃自动拉起一个干净的宿主进程，不再长期占着这些文件。
