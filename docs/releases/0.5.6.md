# 鹿铃 0.5.6

这一版统一了多选框样式，去掉了文件名的半粗体，并修正了扩展商店和此电脑列表的显示问题。

## 改进

- 多选框换成更轻的样式：默认只有一圈淡描边，鼠标移上去才加深并出现浅底，勾选是实心强调色加对勾；列表、设置页与标签管理使用同一套样式。
- 此电脑的名称列不再占满整行：封顶约 46%，腾出的宽度分给「使用情况 / 可用 / 总大小 / 类型」，「类型」列加宽后能完整显示「本地磁盘 · NTFS」。
- 此电脑表头的「可用」「总大小」改为与下方数值相同的左对齐，表头和列不再错位。

## 修复

- 文件名不再对「今天修改」的文件使用半粗体；设置 › 时间显示里对应的开关一并移除。
- 扩展商店的官方增强包卡片此前一直显示「下载并安装」，即使 FFmpeg、图像增强包已经装好。现在会正确显示「已安装」。

## 下载

| 产物 | 说明 |
| --- | --- |
| `LulingSetup-0.5.6.exe` | 标准版，需要时再下引擎 |
