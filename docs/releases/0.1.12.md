# 鹿铃 0.1.12

## 移除两项功能

按作者要求删掉：

- **归档素材（PNG + XML）** —— 移除菜单项、命令与实现
- **项目复选框** —— 移除菜单项、命令、设置项、每行复选框的几何与绘制

## 修复：地址栏历史下拉一直是原来的宽度

根因在菜单框架里：`filter_min_width_`（调用方设置的"至少多宽"）**只在菜单带过滤框时才生效**：

```
minW = filter_fn_ ? (filter_min_width_ > 0 ? filter_min_width_ : 440) * scale
                  : dropdown_ ? ... : 0        ← 没有过滤框就是 0
```

地址栏历史菜单**没有过滤框**，所以传进去的宽度被完全忽略，退回按内容宽度。现在没有过滤框时
同样尊重这个最小值。

## 安装

- `LulingSetup-0.1.12.exe`
- `Luling-0.1.12-portable-win-x64.zip`

**注意**：请把安装包/便携版**复制到桌面等普通目录**再运行——从本会话的工作目录启动会继承沙箱
上下文，写 `%TEMP%` 与安装目录都会被拒（表现为 NSIS 报"写临时文件失败"或 `error 5 拒绝访问`）。
