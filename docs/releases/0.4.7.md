# 鹿铃 0.4.7 · 标题栏时间与日程

这一版新增标题栏时间卡片和本地日程，并修复接管被外部清除、睡眠唤醒后变卡、源码预览复制不完整等问题。

## 标题栏时间

- 标题栏标签区右侧新增一块固定宽度的时间卡片，标签再多也不会把它挤掉。
- 三页轮播：
  - 第一页：时间、日期、星期、农历（含干支年和闰月）；
  - 第二页：节日与节气，无节日时显示下一个节日的倒计时；
  - 第三页：最近日程，最多两条、只取七天内。
- 鼠标悬停卡片可查看当天完整信息与日程详情。
- 设置 → 外观 → 文字与语言 新增「标题栏时间信息」开关，默认开启。

## 日程

- 点击时间卡片打开日程面板；列表最多显示四条，可滚动。
- 支持标题、描述、日期、时间与「不重复 / 每天 / 每周 / 每月」。
- 日期使用带农历和节气的日历选择器，时间用「时 / 分」双列选择器。
- 到期前应用内通知条提醒，同一天只提醒一次。
- 一次性日程过期后自动清除。

## 修复

- 修复「设为默认文件管理器」有时被外部清理后一直显示关闭：启动时会把用户明确开启过的接管自动补回，但不会抢占其他文件管理器的关联。
- 修复睡眠一晚后唤醒变卡：后台宿主的空闲回收改用不含睡眠的时钟，睡一晚不再被当成空闲八小时。
- 修复源码预览复制不完整：预览仍只读 1 MiB，复制时直接读取整份文件（上限 32 MiB）。
