问题修复版：集中处理 GitHub 上反馈的问题，并合并社区贡献的修复。

### 文件操作

- 批量复制小文件更快：64 MB 以下、目标位置没有同名文件时，直接写入最终文件名，不再经过临时文件；大文件和“替换”仍先写临时文件，保证中途失败不会损坏原文件。（#60）
- 同一磁盘内多选移动时直接改名，不再逐个复制后删除；撤销同样有效。（#60）
- 从 7-Zip、WinRAR、Bandizip 等压缩软件拖出文件到 Pulse 时，先把文件暂存下来再处理重名冲突，修复选择“替换”或“保留两者”后提示“找不到路径”。（#55）
- 修复双击打开部分 .json、.md 等文件时提示“找不到文件”。（#55）
- 从浏览器下载列表、压缩软件等来源拖入时，对方要求复制就一定执行复制，不会误删原文件。（感谢 @sdcxb，#61）
- 替换操作失败且无法还原时，会在错误信息中列出保留的备份文件位置。（感谢 @sdcxb，#63）
- 文件被占用导致操作失败后，关闭占用程序再点“重试”，会跳过已经完成的项目。
- 按大小排序时，文件夹按实际总大小排列。（#58）

### 此电脑与导航

- “此电脑”记住视图模式；磁盘按盘符排序；平铺视图显示每个磁盘的用量条和可用空间。
- 在磁盘根目录双击空白处或点“向上”，可以回到“此电脑”；在“此电脑”中分屏，新窗格同样打开“此电脑”。（#68）

### 右键菜单与系统集成

- 第三方右键扩展卡住时，菜单会在 5 秒后先显示其他项目，并在空闲时重启菜单宿主进程，不再越积越多；连续卡住 3 次的扩展会被自动停用。（#65）
- 不再缓存不完整的右键菜单结果，修复 WinRAR 等第三方二级菜单时有时无。（感谢 @sdcxb，#59、#62）
- 右键菜单宿主进程只接受启动它的 Pulse 的请求。（感谢 @sdcxb，#64）
- 卸载时恢复“此电脑”原来的打开方式。
- 系统开启“在标题栏上显示强调色”时，标题栏不再上下两种颜色。（#20）

### 搜索与索引

- 全盘索引服务只返回当前用户有权查看的文件夹中的结果，其他用户的个人文件夹内容不会出现在搜索里。（#66）

### 安装与更新

- 更新改为原地覆盖安装，任务栏和开始菜单里固定的 Pulse 图标在更新后保留。（#72）
- 设置 → 关于与诊断 → 软件更新 新增“自动检查更新”开关，默认开启。

### 界面

- 工具栏的“排序”“分组”“筛选”按钮宽度贴合文字，下拉箭头带有展开动画。
- 高对比度模式下，所有输入框都使用系统配色。
- 文件夹选择器在加载过程中只允许选择已确认存在的文件夹。
- 英文界面中残留的中文已翻译；操作错误信息中显示真实的文件名。

提供 Windows 10/11 x64 安装版、Windows 8.1 兼容版和免安装版。
