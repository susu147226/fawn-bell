# 鹿铃 0.1.6

## 新增：项目复选框

和资源管理器一样，可以给每个文件/文件夹行加一个复选框，方便连续勾选。

- **开启方式**：在列表**空白处右键 → 「项目复选框」**（菜单项带勾选标记表示当前状态）。
- 开启后**每一行左侧出现复选框**，勾选状态与选中状态一致：点行、Ctrl 点、框选都会同步。
- 图标视图（大/中/超大图标）不显示复选框。
- 该菜单项已登记为内建项，可以在「设置 → 右键菜单」里隐藏或调整顺序。
