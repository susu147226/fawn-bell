# 鹿铃 0.4.4 · 预览全文、顶部按钮与文件名修复

这一版修复代码预览只显示片段、预览顶部按钮重叠，以及文件名被无谓省略。

## 快速预览

- 代码与纯文本预览不再只显示片段：解码上限从 12000 字符提高到 1 MiB，普通源码文件会完整显示；超过 1 MiB 的文件才在状态栏标记截断。
- 顶部按钮不再重叠：
  - 「树 / 源码」切换与位置计数依次排开，不再画在同一块区域；
  - 上一项、下一项、更多按「复制」按钮的真实宽度排布，箭头不再压进复制按钮。
- 树 / 源码切换仍会重建一次文本布局，可能有短暂停顿，后续版本优化。

## 文件列表

- 今天修改过的文件名用粗体绘制，但宽度此前按常规字体测量；粗体更宽，导致完整文件名被省略。现在测量和绘制使用同一字体。
- 单列详情模式直接使用整行宽度作为名字可用区，不再受列宽计算影响。
- 名字与悬停按钮争空间时优先保证名字完整，放不下才截断。
