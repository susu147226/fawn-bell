# 鹿铃 0.5.7

这一版重做了磁盘容量条的配色与动画，并修好了表头全选框取消不掉的问题。

## 改进

- 容量条按占用率分四档：低于 50% 绿色、50–79% 蓝色、80–94% 琥珀、95% 以上（或已达到 80% 且剩余不足 1 GB）红色。存储总览、使用情况列、磁贴和侧边栏使用同一套规则。
- 侧边栏的磁盘进度条改为每块盘一种颜色，多块盘一眼可分；占用率进入警戒区间时仍会变成琥珀或红色。
- 回到「此电脑」时，存储总览和列表「使用情况」里的进度条会一起从零展开，不再直接满格出现。
- 多选框的边框改为 1 个物理像素，高缩放比例下不再显得粗；表头全选框的圆角与列表内复选框统一。

## 修复

- 表头全选框在筛选生效或部分条目不可见时，第二次点击无法取消全选。现在按当前可见条目判断，点击即可切换。
