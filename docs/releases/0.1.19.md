# 鹿铃 0.1.19

## 安装前先清空旧版本

更新此前只是覆盖文件，旧版的残留会一直留着。现在安装程序在写入任何东西之前，
先完整清一遍：

- 结束仍在运行的旧版进程
- 停掉并删除 `LulingIndex` 服务（如果你之前开着全盘索引，装完会自动放回去）
- 删掉程序目录、`%LOCALAPPDATA%` / `%APPDATA%` / `%ProgramData%` 下的数据目录、
  快捷方式、卸载登记项与标签菜单注册项
- 数据目录里的**索引、缩略图与内容缓存、网络缓存、日志、崩溃残留**随整棵树一起
  删除，由新版本重建

**你自己的状态会保留**：设置、固定位置与标签、右键菜单定制、地址栏与搜索历史、
窗口布局（数据目录里所有顶层 `.json`）。

> 说明一处刻意保留：**接管文件管理器的注册表没有清**。更新装回同一个目录，接管
> 仍然有效；而里面那份快照是「取消接管」唯一的依据，装更新时删掉它会让接管再也
> 退不回来。卸载时则是相反的顺序（先还原，再删）。

## 修复：0.1.18 把搜索历史的回车改坏了

0.1.18 修好了「地址栏粘贴路径后回车不跳转」，但那条改动范围放得太宽——它让所有
借用输入框的弹出列表都不再接管回车，于是**搜索历史弹窗里回车不再执行高亮的那条
建议**。现在这条行为改成只对地址栏的位置历史生效。

## 局域网

- **可以看到同一网络里的其他电脑**（此前只列系统「网络」位置的快捷方式）
- **共享拒绝当前凭据时，会像资源管理器那样提示登录**，登录成功后自动重新打开该
  文件夹。凭据不会写入凭据管理器，只在本次会话有效

## 网络位置的显示名可以重命名

在网络位置列表里对一行重命名，名字记进配置；从系统快捷方式导入的项会被收编为
固定项，因此新名字会压过原来导入的名字。

## 安装 / 卸载

- `LulingSetup-0.1.19.exe`
- `Luling-0.1.19-portable-win-x64.zip`

**注意**：请把安装包**复制到桌面等普通目录**再运行——安装程序需要清空安装目录，
从安装目录里直接运行会因自身被占用而留下残留。
