# 鹿铃 0.2.7 · 更新提示来得更快

一个小补丁，只改了一件事：**检查更新的间隔从六小时缩短到 15 分钟**。

0.2.6 修好了「检查失败后 15 分钟重试」，但还有一种情况会错过更新提示：

- 程序自动检查时，新版本刚发布几十秒，GitHub 的加速代理或 CDN 还在返回**上一版**
  的更新清单；
- 这次检查本身是成功的（只是“没有新版本”），于是下一次要再等**六小时**。

现在「检查成功、暂时没有新版本」也改为 **15 分钟**后再查。发布新版本后，一直开着
鹿铃的电脑最迟 15 分钟内就会看到更新提示，不需要重启，也不需要进设置页。

检查仍然走加速代理，国内网络不需要额外配置；每次只下载几百字节的清单，内存和
CPU 开销可以忽略。
