# 鹿铃 0.3.4 · 多窗口操作层与服务器路径修复

这一版修复 0.3.3 的两个问题。

## 多窗口

- 关闭任意一个窗口后，剩下的窗口继续新建文件夹、删除、重命名等操作，不再提示「操作层未启动」。
- 文件操作队列、撤销历史和右键菜单结果由所有窗口共用；操作进度显示在最近使用的窗口。

## 地址栏

- 粘贴只带一个前导反斜杠的服务器地址（如 `\172.16.0.239\Project3\...`）会按网络共享打开，不会再被拼到当前盘符下面。
- 两个反斜杠的 UNC 地址与常规路径行为不变；当前盘上真实存在的文件夹仍按原路径解析。
