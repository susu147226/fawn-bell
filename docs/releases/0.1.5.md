# 鹿铃 0.1.5

## 修复

**地址栏历史下拉的宽度** —— 之前设了宽度却不生效：同时调用 `SetAnchorRect` 会让弹出层按
锚点矩形定宽，把宽度设置覆盖掉。现在只给落点，宽度按"地址栏的 1.8 倍、最少 560"生效，
长路径能看全，并且整体下移让开正在编辑的地址。

**批量重命名默认输入的是"前缀"** —— 之前你在规则框里输入 `time`，会被当成完整的重命名规则，
于是所有文件都叫 `time`、全部报名称冲突。现在简单模式下这个框就是**前缀**，输入 `time`
得到 `time_0.png`、`time_1.png`……序号和扩展名自动补上；切到「更多选项」时文本框会在
"前缀"和"完整规则"两种含义间自动转换，不会丢内容。

**批量重命名的提示文字不再压住文件列表** —— 精简模式下预览区与说明文字位置重叠，现在说明
在上、列表在下。

## 归档素材

仍未定位。这一版在功能入口写了一行追踪到 `%LOCALAPPDATA%\Luling\refile.log`（记录调用时
收到的文件数与前几个路径）。**执行一次「归档素材」后，把这个文件发我**，就能判断是命令没被
派发、还是选中项没传进来、还是其他。

## 说明

关于页的「构建时间 / 构建 ID」是**编译期**写入的，只有重新 configure 才会刷新，之前几版一直
显示 `2026-10-13` 并不代表代码是旧的。本版已重新 configure，时间戳会更新。
