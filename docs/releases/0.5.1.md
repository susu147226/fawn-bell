# 鹿铃 0.5.1

这一版回退了 0.5.0 中对文件操作等待逻辑的调整，删除和复制恢复为原先的行为；其余功能与 0.5.0 一致。

## 本版变化

- 删除操作恢复为原有的等待方式：不再有额外的超时中断，也不会在等待期间重启后台的 Shell 宿主进程。
- 复制操作恢复为原有的重试策略，与之前的版本完全相同。

## 保持不变的改进

- 地址栏路径补全、从当前目录补全相对路径、直接输入文件路径打开。
- 面包屑每一段右侧的箭头列出该目录的子文件夹。
- 筛选框支持拼音匹配。
- 图片与 RAW 增强包按安装包中登记的名称启动。

## 下载

| 产物 | 说明 |
| --- | --- |
| `LulingSetup-0.5.1.exe` | 标准版，需要时再下引擎 |
