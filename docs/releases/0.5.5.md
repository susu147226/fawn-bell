# 鹿铃 0.5.5

这一版把「此电脑」、工作区、收藏夹和排序面板对齐到 Pulse 1.0.60，并补齐了标签管理和空文件夹标识。

## 新增

- 此电脑：新增存储总览卡片与「使用情况 / 可用 / 总大小」列，磁盘、设备、网盘程序入口分成三组；启动后默认停在此电脑。
- 工作区：空状态卡片带「保存当前分栏」，工作区以卡片显示并可折叠。
- 收藏夹可切换成横向收藏栏（Ctrl+Shift+B）：可以把文件或文件夹直接拖进收藏栏，右键可移出收藏或移到分组，按 F6 用键盘浏览。
- 排序面板改为贴在「排序」按钮下方的下拉面板：选中的排序卡片固定不动，键列表在卡片里滑动；滚动和切换排序方式都有过渡动画。
- 设置 › 扩展商店：浏览商店、已安装扩展、管理增强包三个页签，接入 GitHub 扩展目录；扩展命令运行前会列出所需权限并请求确认。
- 标签管理新增标签组、多标签组合视图、标签导入/导出，以及按路径通配符自动打标签的规则。
- 空文件夹使用淡色文件夹图标，并在详细信息视图里带「空」标记。
- 标签栏支持水平滚轮；标签过多时保持可读宽度并横向滚动，滚到两端时对应箭头隐藏。

## 修复

- 切换显示器缩放或修改界面字号后，文件名可能继续沿用旧字号的宽度。
- 标签很多时宽度会被一直压缩，现在固定最小宽度并改为横向滚动。
