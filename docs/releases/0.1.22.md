# 鹿铃 0.1.22

## 修复：更新会把你开着的全盘索引服务关掉

0.1.21 的安装程序在清理旧版本时，会先判断「原来装没装全盘索引服务」，装完再把它放回去。
这个判断用的是 `sc query` 的退出码，而这个退出码在当前环境下**并不可靠**——判断失败时
「原来有服务」就被当成了「没有」，于是**服务被删掉且没有恢复**，全盘索引静默失效。

现在改为**直接读注册表**里的服务项来判断，不再依赖外部进程的退出码。

> 如果你的全盘索引服务被上一版关掉了：在「设置 → 搜索与索引」里重新点一次
> **安装全盘索引服务**即可，或者在安装目录里执行 `Luling.Index.exe --install`。

## 安装 / 卸载：两个安装包

| 产物 | 大小 | 说明 |
| --- | --- | --- |
| `LulingSetup-0.1.22.exe` | 约 7.7 MB | 标准版，不带预览增强包，需要时在设置里下载 |
| `LulingSetup-0.1.22-full.exe` | 约 27 MB | **含全部预览增强包**，装完即用，适合下载源不可达的机器 |
| `Luling-0.1.22-portable-win-x64.zip` | 约 31 MB | 免安装版，**默认含全部预览增强包** |

应用内自动更新指向**标准版**；离线需求请手动下载 full 版或便携版。

**注意**：请把安装包**复制到桌面等普通目录**再运行。
