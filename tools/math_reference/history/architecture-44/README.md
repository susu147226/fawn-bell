# Previous architecture milestone

Frozen copies of the original 44-case corpus, actual KaTeX 0.16.22 observations and actual native comparison before the structures milestone. These preserve the previous acceptance/fallback contracts and evidence while new structures are implemented and verified. In particular, four previously documented fallbacks may become supported only after their parser and layout implementations exist; this archive is not rewritten to imply they were previously supported.

The active corpus and reference scripts are two directories above. This historical corpus hash is recorded in its own reference summary and native comparison.
